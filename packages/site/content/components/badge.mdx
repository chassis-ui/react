## Overview

A `<Badge>` adds counts, labels, or status indicators to content — highlighting new items, notification counts, or other supplementary information alongside any content or component.

## Basic usage

A `<Badge>` scales to suit the size of the parent element by using relative font sizing and `em` units.

<Example>
  <HeadingsExample client:load />
</Example>

A badge composes as part of a link or button to provide a counter.

<Example>
  <ButtonCounterExample client:load />
</Example>

<Callout type="info">
  Badge content can be confusing for screen reader users without proper context. Use semantic
  roles by adding `role="status"` for counters or `role="presentation"` for decorative badges, and
  provide descriptions with `aria-label` to explain the badge's meaning.
</Callout>

<Example>
  <StatusBadgeExample client:load />
</Example>

## Color variants

Set the `color` prop to one of the Chassis themed colors to apply the appropriate background and text colors.

<Example>
  <ColorExample client:load />
</Example>

<Callout type="info">
  Color alone doesn't convey meaning to assistive technology users. Ensure clarity through text
  with adequate contrast, ARIA attributes where needed, and the `.visually-hidden` class for
  screen reader content when color is the only indicator.
</Callout>

### Outline style
