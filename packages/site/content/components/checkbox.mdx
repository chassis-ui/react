## Overview

`<Checkbox>` replaces the browser's default checkbox for selecting one or several options in a list. It renders the wrapper-based `.check-input` markup nested inside a single `<label>` — passing `label` produces an accessible, fully-clickable control with no extra markup.

`<Checkbox>` is built on [React Aria](https://react-spectrum.adobe.com/react-aria/) for keyboard and screen-reader support. It works standalone, or inside a `<CheckboxGroup>` to manage a set of related checkboxes as a single array of selected values.
