## Overview

`Tabs` organizes content into sections, showing one at a time. Unlike hand-wiring a `Nav` to a set of manually-toggled panels, `Tabs` handles keyboard navigation (arrow keys, Home/End), roving tab focus, and the `role="tablist"`/`role="tab"`/`role="tabpanel"` + `aria-selected`/`aria-controls`/`aria-labelledby` wiring between them for you.

Compose a `TabsList` of `TabsTab`s, followed by one `TabsPanel` per tab. A tab and its panel are paired by a matching `id` — not by position, and not by React's own `key` (though you should still give each a `key`, as with any list).

## Pills

Pass `variant="pills"` to `TabsList` for a pill-styled tab list instead of the default underlined tabs.

  <PillsExample client:load />

## Disabled tabs

Add `disabled` to a `TabsTab` to remove it from keyboard navigation and prevent it from being selected.

<Example>
  <DisabledExample client:load />
</Example>

## Controlled selection

Pass `selectedKey`/`onSelectionChange` to `Tabs` to control which tab is selected yourself, e.g. to sync it with the URL. Omit them (use `defaultSelectedKey` instead) to let `Tabs` manage selection internally.
