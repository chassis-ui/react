## Sizing

Set heights using `size` property like `size="large"` and `size="small"`.

<Example>
  <CxTextInput type="text" size="large" placeholder="Large input" aria-label="lg input example"/>
  <br/>
  <CxTextInput type="text" placeholder="Default input" aria-label="default input example"/>
  <br/>
  <CxTextInput type="text" size="small" placeholder="Small input" aria-label="sm input example"/>
</Example>

## Disabled

Add the `disabled` boolean attribute on an input to give it a grayed out appearance and remove pointer events.

<Example>
  <CxTextInput type="text" placeholder="Disabled input" aria-label="Disabled input example" disabled/>
  <br/>
  <CxTextInput type="text" placeholder="Disabled readonly input" aria-label="Disabled input example" disabled readOnly/>
  <br/>
</Example>

## Readonly

Add the `readOnly` boolean attribute on an input to prevent modification of the input's value. Read-only inputs appear lighter (just like disabled inputs), but retain the standard cursor.

<Example>
  <CxTextInput type="text" placeholder="Readonly input here..." aria-label="readonly input example" readOnly/>
</Example>

## Readonly plain text

If you want to have `<input readonly>` elements in your form styled as plain text, use the `plainText` boolean property to remove the default form field styling and preserve the correct margin and padding.

<Example>
  <CxRow className="mb-medium">
    <CxFormLabel htmlFor="staticEmail" className="small:col-2 col-form-label">Email</CxFormLabel>
    <CxCol sm={10}>
      <CxTextInput type="text" id="staticEmail" defaultValue="email@example.com" readOnly plainText/>
    </CxCol>
  </CxRow>
  <CxRow className="mb-medium">
    <CxFormLabel htmlFor="inputPassword" className="small:col-2 col-form-label">Password</CxFormLabel>
    <CxCol sm={10}>
      <CxTextInput type="password" id="inputPassword"/>
    </CxCol>
  </CxRow>
</Example>

<Example>
  <CxForm className="row g-3">
    <CxCol xs="auto">
      <CxFormLabel htmlFor="staticEmail2" className="visually-hidden">Email</CxFormLabel>
      <CxTextInput type="text" id="staticEmail2" defaultValue="email@example.com" readOnly plainText/>
    </CxCol>
    <CxCol xs="auto">
      <CxFormLabel htmlFor="inputPassword2" className="visually-hidden">Password</CxFormLabel>
      <CxTextInput type="password" id="inputPassword2" placeholder="Password"/>
    </CxCol>
    <CxCol xs="auto">
      <CxButton type="submit" className="mb-medium">Confirm identity</CxButton>
    </CxCol>
  </CxForm>
</Example>

## Types

`CxTextInput` accepts any single-line, text-valued native `type`: `text`, `password`, `email`, `tel`, `url`, `search`, `date`, `datetime-local`, `month`, `week`, and `time`. The value is passed straight through to the underlying `<input>`, so browser-native behaviors like password reveal toggles, email validation, and date pickers all work as expected.

<Example>
  <CxTextInput type="email" placeholder="name@example.com" aria-label="email example" />
  <br/>
  <CxTextInput type="password" placeholder="Password" aria-label="password example" />
  <br/>
  <CxTextInput type="date" aria-label="date example" />
</Example>

Color and file inputs need bespoke rendering (a swatch, a themed file-selector button) that a plain text field can't provide, so they have their own dedicated components instead — see [File Input](/react/docs/forms/file-input) and [Color Input](/react/docs/forms/color-input). For a richer date-picking experience with a calendar popup, see [Date Picker](/react/docs/forms/datepicker).
