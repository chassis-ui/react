## Approach

Browser default radios are replaced with the help of `<CxFormRadio>`, for selecting one option from many. It renders the modern, wrapper-based `.check-input` markup nested inside a single `<label>` — passing `label` gives you an accessible, fully-clickable control with no extra markup required.

`<CxFormRadio>` is built on [React Aria](https://react-spectrum.adobe.com/react-aria/) for full keyboard and screen-reader support. Radios have no meaningful standalone state — a radio only makes sense as part of a mutually-exclusive set — so `<CxFormRadio>` must always be rendered inside a `<CxFormRadioGroup>`, which manages selection and arrow-key navigation between options.

## Radios

Radios are always rendered inside a `<CxFormRadioGroup>`, which owns selection and gives the group a `<fieldset>`/`<legend>` so assistive technology announces the group's purpose alongside each option.

Disable a single option by adding `disabled` to that `<CxFormRadio>`, or disable the whole group by adding `disabled` to `<CxFormRadioGroup>`.

Radio groups have a built-in `orientation` property to lay options out on the same horizontal row, which also switches arrow-key navigation from vertical to horizontal.
