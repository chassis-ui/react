import { CxImage } from '@chassis-ui/react'


## Responsive images

Images in Chassis are made responsive with `fluid` property. This applies `max-width: 100%;` and `height: auto;` to the image so that it scales with the parent element.

<Example>
  <CxImage fluid src="https://placehold.co/800x400" />
</Example>

```jsx
<CxImage fluid src="/images/react.jpg" />
```

## Image thumbnails

In addition to our border-radius utilities, you can use prop`thumbnail` to give an image a rounded 1px border appearance.

<Example>
  <CxImage rounded thumbnail src="https://placehold.co/800x400" width={200} height={200} />
</Example>

```jsx
<CxImage rounded thumbnail src="/images/react400.jpg" width={200} height={200} />
```

## Aligning images

Align images with the `align` property.

<Example>
  <div className="clearfix">
    <CxImage align="start" rounded src="https://placehold.co/800x400" width={200} height={200} />
    <CxImage align="end" rounded src="https://placehold.co/800x400" width={200} height={200} />
  </div>
</Example>

```jsx
<div className="clearfix">
  <CxImage align="start" rounded src="/images/react400.jpg" width={200} height={200} />
  <CxImage align="end" rounded src="/images/react400.jpg" width={200} height={200} />
</div>
```

<Example>
  <div className="clearfix">
    <CxImage align="center" rounded src="https://placehold.co/800x400" width={200} height={200} />
  </div>
</Example>

```jsx
<div className="clearfix">
  <CxImage align="center" rounded src="/images/react400.jpg" width={200} height={200} />
</div>
```

<Example>
  <div className="text-center">
    <CxImage rounded src="https://placehold.co/800x400" width={200} height={200} />
  </div>
</Example>

```jsx
<div className="text-center">
  <CxImage rounded src="/images/react400.jpg" width={200} height={200} />
</div>
```
