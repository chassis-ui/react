## Example

Provide an option to dismiss or close a component with `<CloseButton>`. Default styling is limited, but highly customizable. Modify the Sass variables to replace the default `background-image`.

## Disabled state

Disabled close buttons change their `opacity`. We've also applied `pointer-events: none` and `user-select: none` to preventing hover and active states from triggering.
