## Overview

Dropdowns are toggleable, contextual overlays for displaying lists of links and more.

Dropdowns are built on a third party library, [Popper.js](https://popper.js.org/), which provides dynamic positioning and viewport detection. Popper.js isn't used to position dropdowns in navbars though as dynamic positioning isn't required.

## Examples

Bind the dropdown's toggle and the dropdown menu inside `<CxDropdown>`, or different element that declares `position: relative;`. Dropdowns can be triggered from `<a>` or `<button>` elements to better fit your possible requirements.

### Single button

Here's how you can put them to work with either `<button>` elements:

<Example>
  <CxDropdown>
    <CxDropdownToggle context="secondary">Dropdown button</CxDropdownToggle>
    <CxDropdownMenu>
      <CxDropdownItem href="#">Action</CxDropdownItem>
      <CxDropdownItem href="#">Another action</CxDropdownItem>
      <CxDropdownItem href="#">Something else here</CxDropdownItem>
    </CxDropdownMenu>
  </CxDropdown>
</Example>

And with `<a>` elements:

<Example>
  <CxDropdown>
    <CxDropdownToggle href="#" context="secondary">
      Dropdown button
    </CxDropdownToggle>
    <CxDropdownMenu>
      <CxDropdownItem href="#">Action</CxDropdownItem>
      <CxDropdownItem href="#">Another action</CxDropdownItem>
      <CxDropdownItem href="#">Something else here</CxDropdownItem>
    </CxDropdownMenu>
  </CxDropdown>
</Example>

The best part is you can do this with any button variant, too:

<Example>
  <>
    {['primary', 'secondary', 'success', 'info', 'warning', 'danger'].map((context, index) => (
      <CxDropdown variant="btn-group" key={index}>
        <CxDropdownToggle context={context}>{context}</CxDropdownToggle>
        <CxDropdownMenu>
          <CxDropdownItem href="#">Action</CxDropdownItem>
          <CxDropdownItem href="#">Another action</CxDropdownItem>
          <CxDropdownItem href="#">Something else here</CxDropdownItem>
          <CxDropdownDivider />
          <CxDropdownItem href="#">Separated link</CxDropdownItem>
        </CxDropdownMenu>
      </CxDropdown>
    ))}
  </>
</Example>

### Split button

Similarly, create split button dropdowns with virtually the same markup as single button dropdowns, but with the addition of boolean prop `split` for proper spacing around the dropdown caret.

We use this extra class to reduce the horizontal `padding` on either side of the caret by 25% and remove the `margin-left` that's attached for normal button dropdowns. Those additional changes hold the caret centered in the split button and implement a more properly sized hit area next to the main button.

<Example>
  <>
    {['primary', 'secondary', 'success', 'info', 'warning', 'danger'].map((context, index) => (
      <CxDropdown variant="btn-group" key={index}>
        <CxButton context={context}>{context}</CxButton>
        <CxDropdownToggle context={context} split />
        <CxDropdownMenu>
          <CxDropdownItem href="#">Action</CxDropdownItem>
          <CxDropdownItem href="#">Another action</CxDropdownItem>
          <CxDropdownItem href="#">Something else here</CxDropdownItem>
          <CxDropdownDivider />
          <CxDropdownItem href="#">Separated link</CxDropdownItem>
        </CxDropdownMenu>
      </CxDropdown>
    ))}
  </>
</Example>

## Dark dropdowns

Opt into darker dropdowns to match a dark navbar or custom style by set `dark` property. No changes are required to the dropdown items.

<Example>
  <CxDropdown dark>
    <CxDropdownToggle context="secondary">Dropdown button</CxDropdownToggle>
    <CxDropdownMenu>
      <CxDropdownItem href="#">Action</CxDropdownItem>
      <CxDropdownItem href="#">Another action</CxDropdownItem>
      <CxDropdownItem href="#">Something else here</CxDropdownItem>
      <CxDropdownDivider />
      <CxDropdownItem href="#">Separated link</CxDropdownItem>
    </CxDropdownMenu>
  </CxDropdown>
</Example>

And putting it to use in a navbar:

<Example>
  <CxNavbar expand="large" colorScheme="dark" className="bg-dark">
    <CxContainer fluid>
      <CxNavbarBrand href="#">Navbar</CxNavbarBrand>
      <CxNavbarToggler aria-label="Toggle navigation" aria-expanded={true} />
      <CxCollapse className="navbar-collapse" visible={true}>
        <CxNavbarNav>
          <CxDropdown dark component="li" variant="nav-item">
            <CxDropdownToggle>Dropdown</CxDropdownToggle>
            <CxDropdownMenu>
              <CxDropdownItem href="#">Action</CxDropdownItem>
              <CxDropdownItem href="#">Another action</CxDropdownItem>
              <CxDropdownItem href="#">Something else here</CxDropdownItem>
              <CxDropdownDivider />

</Example>

## Menu items

Historically dropdown menu contents _had_ to be links, but that's no longer the case with v4. Now you can optionally use `<button>` elements in your dropdowns instead of just `<a>`s.

<Example>
  <CxDropdown>
    <CxDropdownToggle context="secondary">Dropdown</CxDropdownToggle>
    <CxDropdownMenu>
      <CxDropdownItem component="button">Action</CxDropdownItem>
      <CxDropdownItem component="button">Another action</CxDropdownItem>
      <CxDropdownItem component="button">Something else here</CxDropdownItem>
      <CxDropdownDivider />
      <CxDropdownItem component="button">Separated link</CxDropdownItem>
    </CxDropdownMenu>
  </CxDropdown>
</Example>

You can also create non-interactive dropdown items with `<CxDropdownItemPlain>`.

<Example>
  <div className="border rounded py-2">
    <CxDropdownItemPlain>Dropdown item text</CxDropdownItemPlain>
    <CxDropdownItem href="#">Action</CxDropdownItem>
    <CxDropdownItem href="#">Another action</CxDropdownItem>
    <CxDropdownItem href="#">Something else here</CxDropdownItem>
  </div>
</Example>

### Active

Set boolean property `active` to **style item as active**.

In the following example we use `div` instead of `<CxDropdownMenu>` to show `<CxDropdownMenu>` content.

<Example>
  <div className="border rounded py-2">
    <CxDropdownItem href="#">Regular link</CxDropdownItem>
    <CxDropdownItem href="#" active>
      Active link
    </CxDropdownItem>
    <CxDropdownItem href="#">Another link</CxDropdownItem>
  </div>
</Example>

### Disabled

Add `disabled` boolean property to items in the dropdown to **style them as disabled**.

In the following example we use `div` instead of `<CxDropdownMenu>` to show `<CxDropdownMenu>` content.

<Example>
  <div className="border rounded py-2">
    <CxDropdownItem href="#">Regular link</CxDropdownItem>
    <CxDropdownItem href="#" disabled>
      Disabled link
    </CxDropdownItem>
    <CxDropdownItem href="#">Another link</CxDropdownItem>
  </div>
</Example>

## Menu alignment

By default, a dropdown menu is automatically positioned 100% from the top and along the left side of its parent. Add `aligment="end"` to right align the dropdown menu.

<Callout context="info">
  <strong>Heads up!</strong> Dropdowns are positioned thanks to Popper.
</Callout>

<Example>
  <CxDropdown alignment="end">
    <CxDropdownToggle context="secondary">Right-aligned menu example</CxDropdownToggle>
    <CxDropdownMenu>
      <CxDropdownItem href="#">Action</CxDropdownItem>
      <CxDropdownItem href="#">Another action</CxDropdownItem>
      <CxDropdownItem href="#">Something else here</CxDropdownItem>
      <CxDropdownDivider />
      <CxDropdownItem href="#">Separated link</CxDropdownItem>
    </CxDropdownMenu>
  </CxDropdown>
</Example>

### Responsive alignment

If you use responsive alignment, dynamic positioning is disabled.

To align **right** the dropdown menu with the given breakpoint or larger, add `aligment="xs|sm|md|lg|xl|xxl: end"`.

<Example>
  <CxDropdown alignment={{ lg: 'end' }}>
    <CxDropdownToggle context="secondary">
      Left-aligned but right aligned when large screen
    </CxDropdownToggle>
    <CxDropdownMenu>
      <CxDropdownItem href="#">Action</CxDropdownItem>
      <CxDropdownItem href="#">Another action</CxDropdownItem>
      <CxDropdownItem href="#">Something else here</CxDropdownItem>
      <CxDropdownDivider />
      <CxDropdownItem href="#">Separated link</CxDropdownItem>
    </CxDropdownMenu>
  </CxDropdown>
</Example>

To align **left** the dropdown menu with the given breakpoint or larger, add `aligment="xs|sm|md|lg|xl|xxl: start"`.

<Example>
  <CxDropdown alignment={{ xs: 'end', lg: 'start' }}>
    <CxDropdownToggle context="secondary">
      Right-aligned but left aligned when large screen
    </CxDropdownToggle>
    <CxDropdownMenu>
      <CxDropdownItem href="#">Action</CxDropdownItem>
      <CxDropdownItem href="#">Another action</CxDropdownItem>
      <CxDropdownItem href="#">Something else here</CxDropdownItem>
      <CxDropdownDivider />
      <CxDropdownItem href="#">Separated link</CxDropdownItem>
    </CxDropdownMenu>
  </CxDropdown>
</Example>

## Menu content

### Headers

Add a header to label sections of actions in any dropdown menu.

In the following example we use `div` instead of `<CxDropdownMenu>` to show `<CxDropdownMenu>` content.

<Example>
  <div className="border rounded py-2">
    <CxDropdownHeader>Dropdown header</CxDropdownHeader>
    <CxDropdownItem href="#">Action</CxDropdownItem>
    <CxDropdownItem href="#">Another action</CxDropdownItem>
  </div>
</Example>

### Dividers

Separate groups of related menu items with a divider.

In the following example we use `div` instead of `<CxDropdownMenu>` to show `<CxDropdownMenu>` content.

<Example>
  <div className="border rounded py-2">
    <CxDropdownItem href="#">Action</CxDropdownItem>
    <CxDropdownItem href="#">Another action</CxDropdownItem>
    <CxDropdownItem href="#">Something else here</CxDropdownItem>
    <CxDropdownDivider />
    <CxDropdownItem href="#">Separated link</CxDropdownItem>
  </div>
</Example>

### Text

Place any freeform text within a dropdown menu with text. Note that you'll likely need additional sizing styles to constrain the menu width.

<Example>
  <div className="border rounded p-4 medium:text-emphasis" style={{ maxWidth: '200px' }}>
    <p>Some example text that's free-flowing within the dropdown menu.</p>
    <p className="mb-0">And this is more example text.</p>
  </div>
</Example>

### Forms

Put a form within a dropdown menu, or make it into a dropdown menu.

<Example>
  <div className="border rounded py-2">
    <CxForm className="px-4 py-4">
      <div className="mb-3">
        <CxFormLabel htmlFor="exampleDropdownFormEmail1">Email address</CxFormLabel>
        <CxFormInput type="email" id="exampleDropdownFormEmail1" placeholder="email@example.com" />
      </div>
      <div className="mb-3">
        <CxFormLabel htmlFor="exampleDropdownFormPassword1">Password</CxFormLabel>
        <CxFormInput type="password" id="exampleDropdownFormPassword1" placeholder="Password" />
      </div>
      <div className="mb-3">
        <CxFormCheck id="dropdownCheck" label="Remember me" />
      </div>
      <CxButton type="submit">Sign in</CxButton>
    </CxForm>
    <CxDropdownDivider />
    <CxDropdownItem href="#">New around here? Sign up</CxDropdownItem>
    <CxDropdownItem href="#">Forgot password?</CxDropdownItem>
  </div>
</Example>
