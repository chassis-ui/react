## Accessibility

Assistive technology only announces a set of buttons as grouped when the group carries an explicit `role` — `role="group"` for a button group, `role="toolbar"` for a `<ButtonToolbar>`. Every group and toolbar also needs an understandable label, since most assistive technologies don't otherwise announce the role attribute alone; `aria-label` is used throughout the examples above, though `aria-labelledby` works as well.
