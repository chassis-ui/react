## Example

Wrap a pair of `<TextInput>` and `<FormLabel>` elements in `FloatingInput` to enable floating labels with textual form fields. A `placeholder` is required on each `<TextInput>` as our method of CSS-only floating labels uses the `:placeholder-shown` pseudo-element. Also note that the `<TextInput>` must come first so we can utilize a sibling selector (e.g., `~`).

<Example>
  <FloatingInput className="mb-medium">
    <TextInput type="email" id="floatingInput" placeholder="name@example.com" />
    <FormLabel htmlFor="floatingInput">Email address</FormLabel>
  </FloatingInput>
  <FloatingInput>
    <TextInput type="password" id="floatingPassword" placeholder="Password" />
    <FormLabel htmlFor="exampleFormControlTextarea1">Password</FormLabel>
  </FloatingInput>
</Example>

When there's a `value` already defined, `<FormLabel>`s will automatically adjust to their floated position.

<Example>
  <FloatingInput>
    <TextInput
      type="email"
      id="floatingInputValue"
      placeholder="name@example.com"
      defaultValue="test@example.com"
    />
    <FormLabel htmlFor="floatingInputValue">Input with value</FormLabel>
  </FloatingInput>
</Example>

## Textareas

By default, `<Textarea>`s will be the same height as `<TextInput>`s.

<Example>
  <FloatingInput>
    <Textarea
      id="floatingTextarea"
      placeholder="Leave a comment here"
    ></Textarea>
    <FormLabel htmlFor="floatingTextarea">Comments</FormLabel>
  </FloatingInput>
</Example>

To set a custom height on your `<Textarea>`, do not use the `rows` attribute. Instead, set an explicit `height` (either inline or via custom CSS).

<Example>
  <FloatingInput>
    <Textarea
      placeholder="Leave a comment here"
      id="floatingTextarea2"
      style={{ height: '100px' }}
    ></Textarea>
    <FormLabel htmlFor="floatingTextarea2">Comments</FormLabel>
  </FloatingInput>
</Example>

## Selects

Other than `<TextInput>`, floating labels are only available on `<Select>`s. They work in the same way, but unlike `<TextInput>`s, they'll always show the `<FormLabel>` in its floated state. **Selects with `size` and `multiple` are not supported.**

<Example>
  <FloatingInput>
    <Select id="floatingSelect" aria-label="Floating label select example">
      <option>Open this select menu</option>
      <option value="1">One</option>
      <option value="2">Two</option>
      <option value="3">Three</option>
    </Select>
    <FormLabel htmlFor="floatingSelect">Works with selects</FormLabel>
  </FloatingInput>
</Example>

## Layout

When working with the Chassis grid system, be sure to place form elements within column classes.

<Example>
  <Row xs={{ gutter: 'small' }}>
    <Col md>
      <FloatingInput>
        <TextInput type="email" id="floatingInputGrid" placeholder="name@example.com" defaultValue="email@example.com" />
        <FormLabel htmlFor="floatingInputGrid">Email address</FormLabel>
      </FloatingInput>
    </Col>
    <Col md>
      <FloatingInput>
        <Select id="floatingSelectGrid" aria-label="Floating label select example">
          <option>Open this select menu</option>
          <option value="1">One</option>
          <option value="2">Two</option>
          <option value="3">Three</option>
        </Select>
        <FormLabel htmlFor="floatingSelectGrid">Works with selects</FormLabel>
      </FloatingInput>
    </Col>
  </Row>
</Example>
