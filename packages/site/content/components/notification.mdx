```jsx
const [visible, setVisible] = useState(false)
return (
  <>
    <CxNotification context="primary" dismissible visible={visible} onClose={() => setVisible(false)}>
      A simple primary notification—check it out!
    </CxNotification>
    <CxButton context="primary" onClick={() => setVisible(true)}>Show live notification</CxButton>
  </>
)
```

### Additional content

Notifications can incorporate supplementary components like headings, paragraphs, and dividers.

<Example>
  <CxNotification context="success">
    <CxNotificationHeading tag="h4">Well done!</CxNotificationHeading>
    <p>Aww yeah, you successfully read this important notification message. This example text is going to run a bit longer so that you can see how spacing within a notification works with this kind of content.</p>
    <hr />
    <p className="mb-0">Whenever you need to, be sure to use margin utilities to keep things nice and tidy.</p>
  </CxNotification>
</Example>

```jsx
<CxNotification context="success">
  <CxNotificationHeading tag="h4">Well done!</CxNotificationHeading>
  <p>Aww yeah, you successfully read this important notification message.</p>
  <hr />
  <p className="mb-0">Whenever you need to, be sure to use margin utilities to keep things nice and tidy.</p>
</CxNotification>
```

### Dismissing

Add the `dismissible` prop to let users close the notification.

<Example>
  <CxNotification
    context="warning"
    dismissible
    onClose={() => {
      alert("Dismissed!");
    }}
  >
    <strong>Go right ahead</strong> and click that dismiss button over there on the right.
  </CxNotification>
</Example>

```jsx
<CxNotification
  context="warning"
  dismissible
  onClose={() => alert("Dismissed!")}
>
  <strong>Go right ahead</strong> and click that dismiss button over there on the right.
</CxNotification>
```
