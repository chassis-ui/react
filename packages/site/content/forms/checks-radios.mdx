## Approach

Browser default checkboxes and radios are replaced with the help of `<CxFormCheck>`. Checkboxes are for selecting one or several options in a list, while radios are for selecting one option from many.

## Checks

<Example>
  <CxFormCheck id="flexCheckDefault" label="Default checkbox" />
  <CxFormCheck id="flexCheckChecked" label="Checked checkbox" defaultChecked />
</Example>

```jsx
<CxFormCheck id="flexCheckDefault" label="Default checkbox"/>
<CxFormCheck id="flexCheckChecked" label="Checked checkbox" defaultChecked />
```

## Indeterminate

Checkboxes can utilize the `:indeterminate` pseudo-class when manually set via `indeterminate` property.

<Example>
  <CxFormCheck id="flexCheckIndeterminate" label="Indeterminate checkbox" indeterminate />
</Example>

```jsx
<CxFormCheck id="flexCheckIndeterminate" label="Indeterminate checkbox" indeterminate />
```

### Disabled

Add the `disabled` attribute and the associated `<label>`s are automatically styled to match with a lighter context to help indicate the input's state.

<Example>
  <CxFormCheck label="Disabled checkbox" disabled />
  <CxFormCheck label="Disabled checked checkbox" defaultChecked disabled />
</Example>

```jsx
<CxFormCheck label="Disabled checkbox" disabled/>
<CxFormCheck label="Disabled checked checkbox" defaultChecked disabled/>
```

## Radios

Add the `disabled` attribute and the associated `<label>`s are automatically styled to match with a lighter context to help indicate the input's state.

<Example>
  <CxFormCheck type="radio" name="flexRadioDefault" id="flexRadioDefault1" label="Default radio" />
  <CxFormCheck
    type="radio"
    name="flexRadioDefault"
    id="flexRadioDefault2"
    label="Checked radio"
    defaultChecked
  />
</Example>

```jsx
<CxFormCheck type="radio" name="flexRadioDefault" id="flexRadioDefault1" label="Default radio"/>
<CxFormCheck type="radio" name="flexRadioDefault" id="flexRadioDefault2" label="Checked radio" defaultChecked/>
```

### Disabled

<Example>

  />
  <CxFormCheck

## Switches

A switch has the markup of a custom checkbox but uses the `switch` boolean properly to render a toggle switch. Switches also support the `disabled` attribute.

<Example>
  <CxFormSwitch label="Default switch checkbox input" id="formSwitchCheckDefault" />
  <CxFormSwitch label="Checked switch checkbox input" id="formSwitchCheckChecked" defaultChecked />
  <CxFormSwitch label="Disabled switch checkbox input" id="formSwitchCheckDisabled" disabled />
  <CxFormSwitch
    label="Disabled checked switch checkbox input"
    id="formSwitchCheckCheckedDisabled"
    defaultChecked
    disabled
  />
</Example>

```jsx
<CxFormSwitch label="Default switch checkbox input" id="formSwitchCheckDefault"/>
<CxFormSwitch label="Checked switch checkbox input" id="formSwitchCheckChecked" defaultChecked/>
<CxFormSwitch label="Disabled switch checkbox input" id="formSwitchCheckDisabled" disabled/>
<CxFormSwitch label="Disabled checked switch checkbox input" id="formSwitchCheckCheckedDisabled" defaultChecked disabled/>
```

### Sizes

<Example>
  <CxFormSwitch label="Default switch checkbox input" id="formSwitchCheckDefault" />
  <CxFormSwitch size="large" label="Large switch checkbox input" id="formSwitchCheckDefaultLg" />
  <CxFormSwitch size="xlarge" label="Extra large switch checkbox input" id="formSwitchCheckDefaultXL" />
</Example>

```jsx
<CxFormSwitch label="Default switch checkbox input" id="formSwitchCheckDefault"/>
<CxFormSwitch size="large" label="Large switch checkbox input" id="formSwitchCheckDefaultLg"/>
```


## Inline

Group checkboxes or radios on the same horizontal row by adding `inline` boolean property to any `<CxFormCheck>`.

<Example>
  <CxFormCheck inline id="inlineCheckbox1" value="option1" label="1" />
  <CxFormCheck inline id="inlineCheckbox2" value="option2" label="2" />
  <CxFormCheck inline id="inlineCheckbox3" value="option3" label="3 (disabled)" disabled />
</Example>

```jsx
<CxFormCheck inline id="inlineCheckbox1" value="option1" label="1"/>
<CxFormCheck inline id="inlineCheckbox2" value="option2" label="2"/>
<CxFormCheck inline id="inlineCheckbox3" value="option3" label="3 (disabled)" disabled/>
```

```jsx

<CxFormCheck inline type="radio" name="inlineRadioOptions" id="inlineCheckbox2" value="option2" label="2"/>
<CxFormCheck inline type="radio" name="inlineRadioOptions" id="inlineCheckbox3" value="option3" label="3 (disabled)" disabled/>
```

## Toggle buttons

Create button-like checkboxes and radio buttons by using `button` boolean property on the `<CxFormCheck>` component. These toggle buttons can further be grouped in a button group if needed.

### Checkbox toggle buttons

<Example>
  <CxFormCheck
    button={{ context: 'primary' }}
    id="btn-check"
    autoComplete="off"
    label="Single toggle"
  />
</Example>

```jsx
<CxFormCheck button={{ context: 'primary' }} id="btn-check" autoComplete="off" label="Single toggle" />
```
