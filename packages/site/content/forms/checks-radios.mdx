## Approach

Browser default checkboxes and radios are replaced with the help of `<CxFormCheck>` and `<CxFormRadio>`. Checkboxes are for selecting one or several options in a list, while radios are for selecting one option from many. Both render the modern, wrapper-based `.check-input` markup nested inside a single `<label>` — passing `label` gives you an accessible, fully-clickable control with no extra markup required.

Checkboxes and radios are built on [React Aria](https://react-spectrum.adobe.com/react-aria/) for full keyboard and screen-reader support. Radios have no meaningful standalone state — a radio only makes sense as part of a mutually-exclusive set — so `<CxFormRadio>` must always be rendered inside a `<CxFormRadioGroup>`, which manages selection and arrow-key navigation between options. `<CxFormCheck>` works standalone, or inside a `<CxFormCheckGroup>` when you want to manage a set of related checkboxes as a single array of selected values.

## Checks

<Example>
  <CxFormCheck id="flexCheckDefault" label="Default checkbox" />
  <CxFormCheck id="flexCheckChecked" label="Checked checkbox" defaultSelected />
</Example>

## Indeterminate

Checkboxes can utilize the `:indeterminate` pseudo-class when manually set via `indeterminate` property.

<Example>
  <CxFormCheck id="flexCheckIndeterminate" label="Indeterminate checkbox" indeterminate />
</Example>

### Disabled

Add the `disabled` attribute and the associated `<label>`s are automatically styled to match with a lighter context to help indicate the input's state.

<Example>
  <CxFormCheck label="Disabled checkbox" disabled />
  <CxFormCheck label="Disabled checked checkbox" defaultSelected disabled />
</Example>

## Radios

Radios are always rendered inside a `<CxFormRadioGroup>`, which owns selection and gives the group a `<fieldset>`/`<legend>` so assistive technology announces the group's purpose alongside each option.

<Example>
  <RadiosExample client:load />
</Example>

### Disabled

Disable a single option by adding `disabled` to that `<CxFormRadio>`, or disable the whole group by adding `disabled` to `<CxFormRadioGroup>`.

<Example>
  <RadiosDisabledExample client:load />
</Example>

## Switches

A switch has the markup of a custom checkbox but renders as a toggle switch via `<CxFormSwitch>`. Switches also support the `disabled` attribute.

<Example>
  <CxFormSwitch label="Default switch checkbox input" id="formSwitchCheckDefault" />
  <CxFormSwitch label="Checked switch checkbox input" id="formSwitchCheckChecked" defaultSelected />
  <CxFormSwitch label="Disabled switch checkbox input" id="formSwitchCheckDisabled" disabled />
  <CxFormSwitch
    label="Disabled checked switch checkbox input"
    id="formSwitchCheckCheckedDisabled"
    defaultSelected
    disabled
  />
</Example>

### Sizes

<Example>
  <CxFormSwitch size="small" label="Small switch checkbox input" id="formSwitchCheckDefaultSm" />
  <CxFormSwitch label="Default switch checkbox input" id="formSwitchCheckDefault" />
  <CxFormSwitch size="large" label="Large switch checkbox input" id="formSwitchCheckDefaultLg" />
</Example>

## Default (stacked)

  <CxFormCheck id="defaultCheck2" label="Disabled checkbox" disabled />

## Inline

Group checkboxes on the same horizontal row by wrapping them with the `d-flex` and `gap-medium` flex utilities. Radio groups have a built-in `orientation` property that does the same, and also switches arrow-key navigation from vertical to horizontal.

<Example>
  <div className="d-flex gap-medium">
    <CxFormCheck id="inlineCheckbox1" value="option1" label="1" />
    <CxFormCheck id="inlineCheckbox2" value="option2" label="2" />
    <CxFormCheck id="inlineCheckbox3" value="option3" label="3 (disabled)" disabled />
  </div>
</Example>

<Example>
  <RadiosInlineExample client:load />
</Example>

## Sizing

Apply the `size` property (`small` or `large`) to change the size of a checkbox, radio, or switch.

<Example>
  <CxFormCheck size="large" id="checkLarge" label="Large checkbox" />
  <CxFormCheck id="checkMedium" label="Default checkbox" />
  <CxFormCheck size="small" id="checkSmall" label="Small checkbox" />
</Example>

## Toggle buttons

Create button-like checkboxes and radio buttons by using the `button` property on `<CxFormCheck>`/`<CxFormRadio>`. These toggle buttons can further be grouped in a button group if needed.

### Checkbox toggle buttons

<Example>
  <CxFormCheck
    button={{ context: 'primary' }}
    id="button-check"
    autoComplete="off"
    label="Single toggle"
  />
</Example>

<Example>
  <CxFormCheck
    button={{ context: 'primary' }}
    id="button-check-2"
    autoComplete="off"
    label="Checked"
    defaultSelected

</Example>

<Example>

    button={{ context: 'primary' }}
