## About

Lists in Chassis CSS provide structured containers for related content with consistent styling and behavior. Beyond simple lists, they support interactive elements, custom content, and integration with other components—all while maintaining design token consistency with your broader interface.

## Data-driven usage

Pass an `items` array to render the list from data. Each item accepts `label`, `href`, `color`, `active`, and `disabled`.

<Example>
  <List
    items={[
      { label: 'Dashboard', href: '#', active: true },
      { label: 'Profile', href: '#' },
      { label: 'Settings', href: '#' },
      { label: 'Billing', href: '#', disabled: true },
    ]}
  />
</Example>

With context colors:

<Example>
  <List
    items={[
      { label: 'Default item' },
      { label: 'Primary item', color: 'primary' },
      { label: 'Success item', color: 'success' },
      { label: 'Danger item', color: 'danger' },
      { label: 'Warning item', color: 'warning' },
    ]}
  />
</Example>

## Basic example

The foundation of the list component is an unordered list built with `<List>` and `<ListItem>`. This structure establishes consistent spacing, borders, and typography through Chassis's design token system.

<Example>
  <List>
    <ListItem>Cras justo odio</ListItem>
    <ListItem>Dapibus ac facilisis in</ListItem>
    <ListItem>Morbi leo risus</ListItem>
    <ListItem>Porta ac consectetur ac</ListItem>
    <ListItem>Vestibulum at eros</ListItem>
  </List>
</Example>

## Active items

Add `active` boolean property to a `<ListItem>` to show the current active selection. For better accessibility, active items automatically get an `aria-current="true"` attribute.

<Example>
  <List>
    <ListItem active>Cras justo odio</ListItem>
    <ListItem>Dapibus ac facilisis in</ListItem>
    <ListItem>Morbi leo risus</ListItem>
    <ListItem>Porta ac consectetur ac</ListItem>
    <ListItem>Vestibulum at eros</ListItem>
  </List>
</Example>

## Disabled items

Add `disabled` boolean property to a `<ListItem>` to make it appear disabled. Disabled items automatically get an `aria-disabled="true"` attribute.

<Callout context="info">
  <p>
    The disabled state only changes the visual appearance. For interactive elements like links, additional JavaScript is needed to fully disable interaction behavior.
  </p>
</Callout>

<Example>
  <List>
    <ListItem disabled>Cras justo odio</ListItem>
    <ListItem>Dapibus ac facilisis in</ListItem>
    <ListItem>Morbi leo risus</ListItem>
    <ListItem>Porta ac consectetur ac</ListItem>
    <ListItem>Vestibulum at eros</ListItem>
  </List>
</Example>

## Links and buttons

Use `<a>`s or `<button>`s to create _actionable_ list items with hover, disabled, and active states by adding `component="a|button"`. This applies the `.list-action` modifier class, which separates interactive states from standard read-only items, ensuring users receive the appropriate visual affordances.

Use `component="a"` when the action navigates to a new location, and `component="button"` when the action triggers an in-page behavior. Native `<button>`s support the `disabled` attribute, which both visually styles the element and prevents interaction; `<a>`s only get the visual `.disabled` styling and require additional JavaScript to fully prevent interaction.

<Example>
  <List>
    <ListItem component="a" href="#" active>
      Cras justo odio
    </ListItem>
    <ListItem component="a" href="#">
      Dapibus ac facilisis in
    </ListItem>
    <ListItem component="a" href="#">
      Morbi leo risus
    </ListItem>
    <ListItem component="a" href="#">
      Porta ac consectetur ac
    </ListItem>
    <ListItem component="a" href="#" disabled>
      Vestibulum at eros
    </ListItem>
  </List>
</Example>

<Example>
  <List>
    <ListItem component="button" active>
      Cras justo odio
    </ListItem>
    <ListItem component="button">Dapibus ac facilisis in</ListItem>
    <ListItem component="button">Morbi leo risus</ListItem>
    <ListItem component="button">Porta ac consectetur ac</ListItem>
    <ListItem component="button" disabled>
      Vestibulum at eros
    </ListItem>
  </List>
</Example>

## Layout variations

### Flush list

Add `flush` boolean property to remove outer borders and rounded corners, rendering list items edge-to-edge in a parent container (e.g., cards).

<Example>
  <List flush>
    <ListItem>Cras justo odio</ListItem>
    <ListItem>Dapibus ac facilisis in</ListItem>
    <ListItem>Morbi leo risus</ListItem>
    <ListItem>Porta ac consectetur ac</ListItem>
    <ListItem>Vestibulum at eros</ListItem>
  </List>
</Example>

### Plain layout

Add `plain` boolean property for a minimal list that removes outer borders, rounded corners, and horizontal padding. Creates a sleek appearance suitable for main content areas like search results or content feeds.

<Example>
  <List plain>
    <ListItem>Cras justo odio</ListItem>
    <ListItem>Dapibus ac facilisis in</ListItem>
    <ListItem>Morbi leo risus</ListItem>
    <ListItem>Porta ac consectetur ac</ListItem>
    <ListItem>Vestibulum at eros</ListItem>
  </List>
</Example>

<Callout context="info">
  <p>
    Both `flush` and `plain` remove outer borders and rounded corners. The key difference is that `plain` also removes horizontal padding for a more compact appearance.
  </p>
</Callout>

### Numbered lists

Add `numbered` boolean property to sequentially number list items. For semantic correctness, pair this with `component="ol"`, though the numbering is generated through CSS counters rather than browser defaults.

<Example>
  <List component="ol" numbered>
    <ListItem>A list item</ListItem>
    <ListItem>A list item</ListItem>
    <ListItem>A list item</ListItem>
  </List>
</Example>

### Horizontal layout

Add `layout="horizontal"` to switch a list from column to row layout across all breakpoints. Adjacent items share a single border edge, and outer corners remain rounded while inner corners are squared off.

Responsive variants use [container queries](/react/docs/layout/breakpoints#container-queries) — each `layout="{breakpoint}:horizontal"` value activates at or above the specified container width. Wrap the list in a `.contains-inline` container to establish the container context.

<Callout context="warning">
  <p>`layout="horizontal"` cannot be combined with `flush` — the flush variant removes inline borders that separate items in the horizontal layout.</p>
</Callout>

<Example>
  <div className="contains-inline">
    <List className="mb-medium" layout="horizontal">
      <ListItem>Cras justo odio</ListItem>
      <ListItem>Dapibus ac facilisis in</ListItem>
      <ListItem>Morbi leo risus</ListItem>
    </List>
    <List className="mb-medium" layout="small:horizontal">
      <ListItem>Cras justo odio</ListItem>
      <ListItem>Dapibus ac facilisis in</ListItem>
      <ListItem>Morbi leo risus</ListItem>
    </List>
    <List className="mb-medium" layout="medium:horizontal">
      <ListItem>Cras justo odio</ListItem>
      <ListItem>Dapibus ac facilisis in</ListItem>
      <ListItem>Morbi leo risus</ListItem>
    </List>
    <List layout="large:horizontal">
      <ListItem>Cras justo odio</ListItem>
      <ListItem>Dapibus ac facilisis in</ListItem>
      <ListItem>Morbi leo risus</ListItem>
    </List>
  </div>
</Example>

Apply `.flex-fill` or `.flex-grow-1` utility classes to list items to stretch them across the full list width — `.flex-fill` shares the available width equally, while `.flex-grow-1` grows from each item's natural content width.

<Example>
  <List layout="horizontal">
    <ListItem className="flex-fill">Cras justo odio</ListItem>
    <ListItem className="flex-fill">Dapibus ac facilisis in</ListItem>
    <ListItem className="flex-fill">Vestibulum at eros</ListItem>
  </List>
</Example>

## Contextual classes

Use the `color` property to style list items with a stateful background and color.

<Example>
  <List>
    <ListItem>Dapibus ac facilisis in</ListItem>
    {['primary', 'secondary', 'success', 'danger', 'warning', 'info'].map(
      (color, index) => (
        <ListItem color={color} key={index}>
          A simple {color} list item
        </ListItem>
      ),
    )}
  </List>
</Example>

Contextual classes also work with `<a>`s or `<button>`s. Note the addition of the hover styles here not present in the previous example. Also supported is the `active` state; apply it to indicate an active selection on a contextual interactive item.

<Example>
  <List>
    <ListItem component="a" href="#">
      Dapibus ac facilisis in
    </ListItem>
    {['primary', 'secondary', 'success', 'danger', 'warning', 'info'].map(
      (color, index) => (
        <ListItem component="a" href="#" color={color} key={index}>
          A simple {color} list action
        </ListItem>
      ),
    )}
  </List>
</Example>

<Callout context="info">
  <h5>Conveying meaning to assistive technologies</h5>
  <p>
    Using context to add meaning only provides a visual indication, which will not be conveyed to
    users of assistive technologies – such as screen readers. Ensure that information denoted by the
    context is either obvious from the content itself (e.g. the visible text), or is included through
    alternative means, such as additional text hidden with the `.visually-hidden` class.
  </p>
</Callout>

### Context styles

`<List>` also accepts `color` together with a `variant` of `solid`, `outline`, or `smooth` to color the whole list container based on your design system's color palette.

<Example>
  <Row className="medium:row-cols-2 g-large">
    <Col>
      <List color="primary">
        <ListItem>Cras justo odio</ListItem>
        <ListItem>Dapibus ac facilisis in</ListItem>
        <ListItem>Vestibulum at eros</ListItem>
      </List>
    </Col>
    <Col>
      <List color="primary" variant="solid" flush className="rounded">
        <ListItem>Cras justo odio</ListItem>
        <ListItem>Dapibus ac facilisis in</ListItem>
        <ListItem>Vestibulum at eros</ListItem>
      </List>
    </Col>
    <Col>
      <List color="primary" variant="smooth" flush className="rounded">
        <ListItem>Cras justo odio</ListItem>
        <ListItem>Dapibus ac facilisis in</ListItem>
        <ListItem>Vestibulum at eros</ListItem>
      </List>
    </Col>
    <Col>
      <List color="primary" variant="outline">
        <ListItem>Cras justo odio</ListItem>
        <ListItem>Dapibus ac facilisis in</ListItem>
        <ListItem>Vestibulum at eros</ListItem>
      </List>
    </Col>
  </Row>
</Example>

## Checkboxes and radios

Place Chassis checkboxes and radios within list items and customize as needed.

<Example>
  <List>
    <ListItem>
      <Checkbox label="Cras justo odio" />
    </ListItem>
    <ListItem>
      <Checkbox label="Dapibus ac facilisis in" defaultSelected />
    </ListItem>
    <ListItem>
      <Checkbox label="Morbi leo risus" defaultSelected />
    </ListItem>
    <ListItem>
      <Checkbox label="orta ac consectetur ac" />
    </ListItem>
    <ListItem>
      <Checkbox label="Vestibulum at eros" />
    </ListItem>
  </List>
</Example>

And since `<Checkbox>` always renders a `<label>` as its root element, you can apply `.list-item` directly to it for large hit areas, too.

<Example>
  <List>
    <Checkbox className="list-item" label="Cras justo odio" />
    <Checkbox className="list-item" label="Dapibus ac facilisis in" defaultSelected />
    <Checkbox className="list-item" label="Morbi leo risus" defaultSelected />
    <Checkbox className="list-item" label="orta ac consectetur ac" />
    <Checkbox className="list-item" label="Vestibulum at eros" />
  </List>
</Example>
