## Overview

`<Grid>` renders the `.grid` of `@chassis-ui/css`: a `display: grid` container with twelve columns and, between its items, the gutter of the current breakpoint. [`<GridItem>`](#item-placement) places a child on the columns and rows. `<Grid>` replaces [`<Row>`]([[docsref:/components/row]]) and [`<Col>`]([[docsref:/components/column]]), which are deprecated with the flexbox grid they render — see [Migrating from Row/Col](#migrating-from-rowcol). The [Responsive Grid]([[docsref:/patterns/responsive-grid]]) guide builds page layouts from the pieces documented here. For a single row or column of items, [`<Stack>`]([[docsref:/components/stack]]) and [`<Flex>`]([[docsref:/components/flex]]) are a lighter fit.

## Item placement

`<GridItem>` places a child within a `<Grid>`. An item with no placement props is one track wide and takes the next free cell.

### Span

Set `span` to a number from `1` to `12` to size an item to that many column tracks, rendered as the `.col-span-{n}` class. `responsive` changes the span from a breakpoint up. Three `span={6}` items narrow to `span={4}` from the `md` breakpoint:

<Example class="cxd-example-grid text-center">
  <ResponsiveExample client:load />
</Example>

`span="full"` spans every track of the row (`.col-span-full`), whatever the column count. An item that stacks below a breakpoint needs it: without a base `span`, the item is one track wide there, not full width.

<Example class="cxd-example-grid text-center">
  <FullWidthExample client:load />
</Example>

### Start

Set `start` to a column line from `1` to `13` to position an item, independent of the items before it (`.col-start-{n}`). An offset in the flexbox grid was relative to the previous column; a start line is absolute.

<Example class="cxd-example-grid text-center">
  <StartExample client:load />
</Example>

`start="auto"` returns an item to the flow, to undo a start line from a breakpoint up:

```jsx
<GridItem span={6} start={4} responsive={{ md: { start: 'auto' } }} />
```

### Rows

Set `rows` on `<Grid>` for the number of rows in its template, then place an item on them with `rowSpan` (`.row-span-{n}`, 1 to 6) and `rowStart` (`.row-start-{n}`, 1 to 7, or `'auto'`). `responsive` takes both.

<Example class="cxd-example-grid text-center">
  <RowsExample client:load />
</Example>

## Columns and gap

`columns` sets the number of columns and `gap` the space between items. A column count from 1 to 12 renders the `.grid-cols-{n}` class, and a `Spacing` token in `gap` (the scale `<Flex>` and `<Stack>` use) renders the `.gap-{token}` class. Any other `gap` is a raw CSS value — a length, or a `"{row} {column}"` pair — set through the `--cx-grid-gap` custom property. With no `gap`, the grid has the gutter of the breakpoint, from 0.5rem on a phone to 3rem on the widest screens.

<Example class="cxd-example-grid text-center">
  <ColumnsGapExample client:load />
</Example>

`responsive` changes `columns` and `gap` from a breakpoint up, with the same classes. Only a token fits a breakpoint's `gap`, since a raw value has no class.

<Example class="cxd-example-grid text-center">
  <ResponsiveColumnsExample client:load />
</Example>

The `.row-gap-{token}` and `.column-gap-{token}` utilities set one axis, passed through `className`.

## Auto-fill layout

Set `fill` to render `.grid-fill`: equal columns, as many as there are children, with no `columns` to count.

## Nesting

A `<Grid>` inside a `<GridItem>` is a grid of its own, with twelve tracks across the width of the item. It is narrower than the viewport that the gutter follows, so give it a `gap`, and `columns` in place of twelve tracks.

<Example class="cxd-example-grid text-center">
  <NestedExample client:load />
</Example>

A nested grid inherits what the outer grid sets through a custom property: `rows`, a raw `gap`, `min`, and a `columns` above 12. It does not inherit what is rendered as a class: `columns` from 1 to 12 and a token `gap`.

### Subgrid

Set `subgrid` on a `<GridItem>` to give it the column tracks it spans in the parent `<Grid>` instead of tracks of its own, so its children align to the outer columns. `subgrid` is a prop of `<GridItem>` because CSS subgrid only takes effect on an element that is itself a grid item of the parent. A subgrid has a gap and rows of its own: pass it the `gap` of the parent, or its children are narrower than the parent's tracks.

## Migrating from Row/Col

`<Row>` and `<Col>` render the flexbox grid, which `@chassis-ui/css` deprecates in 0.6 and removes in 0.7. Each of their props has a counterpart on `<Grid>` and `<GridItem>`:

<CxTable>
| Row and Col                                        | Grid and GridItem                                               |
| -------------------------------------------------- | --------------------------------------------------------------- |
| `<Row>`                                            | `<Grid>`, with no `<Container>` needed around it                |
| `<Col span={4}>`                                   | `<GridItem span={4}>`                                           |
| `<Col span={12}>`                                  | `<GridItem span="full">`                                        |
| `<Col span={12} responsive={{ md: { span: 6 } }}>` | `<GridItem span="full" responsive={{ md: { span: 6 } }}>`       |
| `<Col span={4} offset={2}>`                        | `<GridItem span={4} start={3}>`                                 |
| `<Col order="first">`                              | `<GridItem className="order-first">`                            |
| `<Row>` with bare `<Col>`s                         | `<Grid fill>` with plain children                               |
| `<Row cols={3}>` with bare `<Col>`s                | `<Grid columns={3}>` with plain children                        |
| `<Row cols={1} responsive={{ md: { cols: 3 } }}>`  | `<Grid columns={1} responsive={{ md: { columns: 3 } }}>`        |
| `<Row gutter="md">`                                | `<Grid gap="md">`                                               |
| `gutterX`, `gutterY`                               | `className="column-gap-{token}"`, `className="row-gap-{token}"` |
| `<Col span="auto">`                                | [`<Flex gap="md">`]([[docsref:/components/flex]]) with plain children |
</CxTable>

Three differences change how a layout behaves:

- **An item with no `span` is one track wide.** A bare `<Col>` shared the row with its siblings, and a `<Col>` with only a responsive span was as wide as the row below that breakpoint. Give such an item `span="full"`, or use a `fill` grid.
- **The gap applies to both axes.** A `<Row>` with no gutter prop had 1.5rem between columns and nothing between rows. A `<Grid>` has the gutter of the breakpoint between both; `className="row-gap-zero"` removes it between rows.
- **A start line is absolute.** `offset` pushed a column away from the one before it, so `start` is the offset plus one only for the first item of a row.

## Scope

**No content-width tracks.** A grid sizes its tracks from the container, not from the content, so `<Col span="auto">` has no grid counterpart: a row of items as wide as their content is a [`<Flex>`]([[docsref:/components/flex]]).

**Placement classes stop at twelve columns and six rows.** `span` and `start` render classes that `@chassis-ui/css` generates up to 12 columns, and `rowSpan` and `rowStart` up to 6 rows. In a grid with more, an item past those needs an inline `style={{ gridColumn: '…' }}`.
