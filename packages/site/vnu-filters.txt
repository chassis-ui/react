# Nu Html Checker messages this site leaves out, one regular expression per line.

# react-aria writes explicit roles on native elements: role="button" on <button>, and row,
# gridcell, columnheader and rowgroup on the tables of Calendar, Table and DataGrid.
The “[a-z]+” role is unnecessary for element “[a-z]+”\.
The “role” attribute must not be used on a “(td|tr|th)” element which has a “table” ancestor.*

# Astro writes the style of its islands into the first island of a page, as plain rules. vnu
# 26.10.9 wants every style rule of a “style” in “body” inside an “@scope” rule.
Style rule “astro-island,astro-slot,astro-static-slot” not allowed outside an “@scope” rule in a “style” element in “body”\.

# An example's own headings sit under the page's headings, whatever level they start at.
The heading “h[1-6]” \(with computed level [1-6]\) follows the heading “h[1-6]”.*

# A SkeletonLoader inside a card title leaves the heading empty while it loads.
Empty heading\.

# PasswordStrength renders role="meter progressbar"; vnu does not know the ARIA 1.2 meter role.
Discarding unrecognized token “meter” from value of attribute “role”.*

# Link's disabled anchor keeps its href, with aria-disabled and tabindex="-1".
An “aria-disabled” attribute whose value is “true” should not be specified on an “a” element that has an “href” attribute\.
