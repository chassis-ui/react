## Example

Wrap a pair of `<CxFormInput>` and `<CxFormLabel>` elements in `CxFormFloating` to enable floating labels with textual form fields. A `placeholder` is required on each `<CxFormInput>` as our method of CSS-only floating labels uses the `:placeholder-shown` pseudo-element. Also note that the `<CxFormInput>` must come first so we can utilize a sibling selector (e.g., `~`).

<Example>
  <CxFormFloating className="mb-3">
    <CxFormInput type="email" id="floatingInput" placeholder="name@example.com" />
    <CxFormLabel htmlFor="floatingInput">Email address</CxFormLabel>
  </CxFormFloating>
  <CxFormFloating>
    <CxFormInput type="password" id="floatingPassword" placeholder="Password" />
    <CxFormLabel htmlFor="exampleFormControlTextarea1">Password</CxFormLabel>
  </CxFormFloating>
</Example>

```jsx
<CxFormFloating className="mb-3">
  <CxFormInput type="email" id="floatingInput" placeholder="name@example.com" />
  <CxFormLabel htmlFor="floatingInput">Email address</CxFormLabel>
</CxFormFloating>
<CxFormFloating>
  <CxFormInput type="password" id="floatingPassword" placeholder="Password" />
  <CxFormLabel htmlFor="exampleFormControlTextarea1">Password</CxFormLabel>
</CxFormFloating>
```

When there's a `value` already defined, `<CxFormLabel>`s will automatically adjust to their floated position.

<Example>
  <CxFormFloating>
    <CxFormInput
      type="email"
      id="floatingInputValue"
      placeholder="name@example.com"
      defaultValue="test@example.com"
    />
    <CxFormLabel htmlFor="floatingInputValue">Input with value</CxFormLabel>
  </CxFormFloating>
</Example>

```jsx
<CxFormFloating>
  <CxFormInput
    type="email"
    id="floatingInputValue"
    placeholder="name@example.com"
    defaultValue="test@example.com"
  />
  <CxFormLabel htmlFor="floatingInputValue">Input with value</CxFormLabel>
</CxFormFloating>
```

## Textareas

By default, `<CxFormTextarea>`s will be the same height as `<CxFormInput>`s.

<Example>
  <CxFormFloating>
    <CxFormTextarea
      id="floatingTextarea"
      placeholder="Leave a comment here"
    ></CxFormTextarea>
    <CxFormLabel htmlFor="floatingTextarea">Comments</CxFormLabel>
  </CxFormFloating>
</Example>

```jsx
<CxFormFloating>
  <CxFormTextarea
    id="floatingTextarea"
    placeholder="Leave a comment here"
  ></CxFormTextarea>
  <CxFormLabel htmlFor="floatingTextarea">Comments</CxFormLabel>
</CxFormFloating>
```

To set a custom height on your `<CxFormTextarea>`, do not use the `rows` attribute. Instead, set an explicit `height` (either inline or via custom CSS).

<Example>
  <CxFormFloating>
    <CxFormTextarea
      placeholder="Leave a comment here"
      id="floatingTextarea2"
      style={{ height: '100px' }}
    ></CxFormTextarea>
    <CxFormLabel htmlFor="floatingTextarea2">Comments</CxFormLabel>
  </CxFormFloating>
</Example>

```jsx
<CxFormFloating>
  <CxFormTextarea
    placeholder="Leave a comment here"
    id="floatingTextarea2"
    style={{ height: '100px' }}
  ></CxFormTextarea>
  <CxFormLabel htmlFor="floatingTextarea2">Comments</CxFormLabel>
</CxFormFloating>
```

## Selects

Other than `<CxFormInput>`, floating labels are only available on `<CxFormSelect>`s. They work in the same way, but unlike `<CxFormInput>`s, they'll always show the `<CxFormLabel>` in its floated state. **Selects with `size` and `multiple` are not supported.**

<Example>
  <CxFormFloating>
    <CxFormSelect id="floatingSelect" aria-label="Floating label select example">
      <option>Open this select menu</option>
      <option value="1">One</option>
      <option value="2">Two</option>
      <option value="3">Three</option>
    </CxFormSelect>
    <CxFormLabel htmlFor="floatingSelect">Works with selects</CxFormLabel>
  </CxFormFloating>
</Example>

```jsx
<CxFormFloating>
  <CxFormSelect id="floatingSelect" aria-label="Floating label select example">
    <option>Open this select menu</option>
    <option value="1">One</option>
    <option value="2">Two</option>
    <option value="3">Three</option>
  </CxFormSelect>
  <CxFormLabel htmlFor="floatingSelect">Works with selects</CxFormLabel>
</CxFormFloating>
```

## Layout

When working with the Chassis grid system, be sure to place form elements within column classes.

<Example>
  <CxRow xs={{gutter: 2}}>
    <CxCol md>
      <CxFormFloating>
        <CxFormInput type="email" id="floatingInputGrid" placeholder="name@example.com" defaultValue="email@example.com" />
        <CxFormLabel htmlFor="floatingInputGrid">Email address</CxFormLabel>
      </CxFormFloating>
    </CxCol>
    <CxCol md>
      <CxFormFloating>
        <CxFormSelect id="floatingSelectGrid" aria-label="Floating label select example">
          <option>Open this select menu</option>
          <option value="1">One</option>
          <option value="2">Two</option>
          <option value="3">Three</option>
        </CxFormSelect>
        <CxFormLabel htmlFor="floatingSelectGrid">Works with selects</CxFormLabel>
      </CxFormFloating>
    </CxCol>
  </CxRow>
</Example>

```jsx
<CxRow xs={{gutter: 2}}>
  <CxCol md>
    <CxFormFloating>
      <CxFormInput type="email" id="floatingInputGrid" placeholder="name@example.com" defaultValue="email@example.com" />

  </CxCol>
```
