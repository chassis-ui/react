## Overview

`PasswordStrength` scores a password against a set of weighted criteria (length, character variety, special characters) and renders the result as either four discrete segments or a single growing bar, both styled by chassis-css's `.strength`/`.strength-bar`. It's display-only — pass it the current password value from a controlled `<input>`, and it computes and renders the rest.

## Strength criteria

The default scoring algorithm evaluates passwords based on:

| Criteria                                         | Points |
| ------------------------------------------------ | ------ |
| Meets minimum length (`minLength`, 8 by default) | +1     |
| 4+ characters over `minLength`                   | +1     |
| Contains lowercase letters                       | +1     |
| Contains uppercase letters                       | +1     |
| Contains numbers                                 | +1     |
| Contains special characters                      | +1     |
| Multiple special characters                      | +1     |
| 16+ characters                                   | +1     |

| Level  | Points (default thresholds) |
| ------ | ---------------------------- |
| Weak   | 1–2                          |
| Fair   | 3–4                          |
| Good   | 5–6                          |
| Strong | 7–8                          |

Pass `scorer` to replace this algorithm entirely with a custom `(password) => number` function.

## Accessibility

The meter carries `role="meter"` (via React Aria's `useMeter`) with `aria-valuenow`/`aria-valuemin`/`aria-valuemax` kept in sync with the score, and an accessible name from `aria-label` (defaults to `"Password strength"`). The `.strength-text` feedback element is an `aria-live="polite"` region, so screen reader users hear the level change as they type — the meter is decorative feedback and should always be paired with visible password requirements text, not relied on alone.

## Scope

Built on React Aria's `useMeter` for the accessible display — there's no dedicated password-strength hook, so the scoring algorithm itself is ported directly from chassis-css's vanilla `strength.js` (`weights`/`thresholds`/`scorer` options included) rather than coming from the library.

Unlike the vanilla component, `PasswordStrength` doesn't look up a sibling password `<input>` itself or expose imperative `getStrength()`/`evaluate()` methods or a `strengthChange` DOM event — pass the current password as `value` and read the result declaratively via `onStrengthChange` instead.
