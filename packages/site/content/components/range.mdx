## Overview

`<RangeInput>` renders a custom `<input type="range">` whose track (the background) and thumb (the
value) are styled to appear the same across browsers. Filling the track from the thumb to indicate
progress is only supported natively by Edge Legacy and Firefox, so `RangeInput` doesn't attempt it.

</Example>

## Min and max

Range inputs have implicit values for `min` and `max` — `0` and `100`, respectively. Pass `min` and
`max` to set new bounds.

</Example>

## Steps

By default, range inputs snap to integer values. Pass a `step` value to change the increment — the
example below uses `step="0.5"` to double the number of steps.
