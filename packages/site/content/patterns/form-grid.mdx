For the `<Form>` element's own default behaviors and the `label`/`help`/validation props shared
across every form component, see [Working with Forms]([[docsref:/getting-started/working-with-forms]]).
This page covers structuring a form's layout with the grid system once those pieces are in place.

## Utilities

Margin utilities add basic structure to a form — grouping labels, controls, optional help text,
and validation messaging. Stick to `margin-bottom` utilities in a single direction throughout a
form for consistent spacing.

## Horizontal form

Create horizontal forms with the grid by adding the `.row` class to form groups and using the
`.col-*-*` classes to specify the width of labels and controls. Add `.col-form-label` to a
`<FormLabel>` as well, so it's vertically centered with its associated form control.

Margin or padding utilities may still be needed to fine-tune alignment.

<Example>
  <HorizontalFormExample client:load />
</Example>

### Label sizing

Add `.col-form-label-small` or `.col-form-label-large` on a `<FormLabel>` or `<legend>` to match
the size of a `.small` or `.large` control.

<Example>
  <LabelSizingExample client:load />
</Example>

## Column sizing

Any number of `<Col>`s can go inside a `<Row>`, splitting the available width equally between
them by default. Assign a numbered `span` — like `<Col responsive={{ small: { span: 7 } }}>` — to
a subset of columns, and the remaining `<Col>`s split what's left equally.

<Example>
  <ColumnSizingExample client:load />
</Example>

## Auto-sizing

Add a flexbox utility to vertically center a row's contents, and change `<Col>` to
`<Col span="auto">` so a column takes up only as much space as its content needs.

## Inline forms

Use `<Col span="auto">` to build horizontal layouts. Gutter modifier classes add spacing in both
horizontal and vertical directions, and `.align-items-center` vertically centers the form
elements so the `<Checkbox>` aligns properly.
