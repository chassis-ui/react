## Overview

`<Tooltip>` wraps a single trigger element and shows floating `content` positioned relative to it
on hover. It also shows on focus regardless of the `trigger` setting, so keyboard and
screen-reader users reach the same content a pointer user gets on hover — set `trigger="focus"` to
disable the hover trigger entirely, for a trigger whose hover state already means something else.

</Example>

## Placement

Set `placement` to one of the four cardinal directions, each with `-start`/`-end` variants for
finer alignment along the trigger's edge. Chassis flips the requested direction automatically to
keep the tooltip in view when there isn't enough room for it. Directions mirror automatically when
Chassis renders in RTL.
