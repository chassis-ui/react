import { Switch } from '@chassis-ui/react'

## Approach

A switch has the markup of a custom checkbox but renders as a toggle switch via `<Switch>`. Switches also support the `disabled` attribute.

<Example>
  <Switch label="Default switch checkbox input" id="formSwitchCheckDefault" />
  <Switch label="Checked switch checkbox input" id="formSwitchCheckChecked" defaultSelected />
  <Switch label="Disabled switch checkbox input" id="formSwitchCheckDisabled" disabled />
  <Switch
    label="Disabled checked switch checkbox input"
    id="formSwitchCheckCheckedDisabled"
    defaultSelected
    disabled
  />
</Example>

## Sizes

Apply the `size` property (`small` or `large`) to change the size of a switch.

<Example>
  <Switch size="small" label="Small switch checkbox input" id="formSwitchCheckDefaultSm" />
  <Switch label="Default switch checkbox input" id="formSwitchCheckDefault" />
  <Switch size="large" label="Large switch checkbox input" id="formSwitchCheckDefaultLg" />
</Example>

## Context colors

Switches accept a `color` property to color the switch indicator with any of the Chassis contextual colors.

<Example>
  <Switch color="danger" id="switchDanger" label="Danger switch" defaultSelected />
</Example>
