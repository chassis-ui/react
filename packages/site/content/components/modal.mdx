## Examples

### Modal components

Below is a static modal example, with the backdrop and keyboard dismissal disabled so it stays open for illustration. Included are the modal header, modal body (required for `padding`), and modal footer (optional). We ask that you include modal headers with dismiss actions whenever possible, or provide another explicit dismiss action.

<Example customMarkup={`<CxModal backdrop={false} keyboard={false} open>
    <CxModalHeader>
      <CxModalTitle>Modal title</CxModalTitle>
    </CxModalHeader>
    <CxModalBody>Modal body text goes here.</CxModalBody>
    <CxModalFooter>
      <CxButton color="secondary">Close</CxButton>
      <CxButton color="primary">Save changes</CxButton>
    </CxModalFooter>
  </CxModal>`}>
  <CxModal backdrop={false} keyboard={false} style={{ position: 'relative' }} open>

    <CxModalFooter>

      <CxButton color="primary">Save changes</CxButton>
    </CxModalFooter>
  </CxModal>
</Example>

### Static backdrop

If you set a `backdrop` to `static`, your modal will behave as though the backdrop is static, meaning it will not close when clicking outside it. Click the button below to try it.
