## Data-driven usage

Pass an `items` array to render the list group from data. Each item accepts `label`, `href`, `context`, `active`, and `disabled`.

<Example>
  <CxListGroup
    items={[
      { label: 'Dashboard', href: '#', active: true },
      { label: 'Profile', href: '#' },
      { label: 'Settings', href: '#' },
      { label: 'Billing', href: '#', disabled: true },
    ]}
  />
</Example>

```jsx
<CxListGroup
  items={[
    { label: 'Dashboard', href: '#', active: true },
    { label: 'Profile', href: '#' },
    { label: 'Settings', href: '#' },
    { label: 'Billing', href: '#', disabled: true },
  ]}
/>
```

With context colors:

<Example>
  <CxListGroup
    items={[
      { label: 'Default item' },
      { label: 'Primary item', context: 'primary' },
      { label: 'Success item', context: 'success' },
      { label: 'Danger item', context: 'danger' },
      { label: 'Warning item', context: 'warning' },
    ]}
  />
</Example>


## Links and buttons

Use `<a>`s or `<button>`s to create _actionable_ list group items with hover, disabled, and active states by adding `component="a|button"`. We separate these pseudo-classes to ensure list groups made of non-interactive elements (like `<li>`s or `<div>`s) don't provide a click or tap affordance.

## Horizontal

Add `layout="horizontal"` to change the layout of list group items from vertical to horizontal across all breakpoints. Alternatively, choose a responsive variant `.layout="horizontal-{sm|md|lg|xl|xxl}"` to make a list group horizontal starting at that breakpoint's `min-width`. Currently **horizontal list groups cannot be combined with flush list groups.**

<Example>
  <>
    {['', '-small', '-medium', '-large', '-xlarge', '-2xlarge'].map((breakpoint, index) => (
      <CxListGroup className="mb-2" layout={`horizontal${breakpoint}`} key={index}>
        <CxListGroupItem>Cras justo odio</CxListGroupItem>
        <CxListGroupItem>Dapibus ac facilisis in</CxListGroupItem>
        <CxListGroupItem>Morbi leo risus</CxListGroupItem>
      </CxListGroup>
    ))}
  </>
</Example>

```jsx
<>
  {['', '-small', '-medium', '-large', '-xlarge', '-2xlarge'].map((breakpoint, index) => (
    <CxListGroup className="mb-2" layout={`horizontal${breakpoint}`} key={index}>
      <CxListGroupItem>Cras justo odio</CxListGroupItem>
      <CxListGroupItem>Dapibus ac facilisis in</CxListGroupItem>
      <CxListGroupItem>Morbi leo risus</CxListGroupItem>
    </CxListGroup>
  ))}
</>
```

## Contextual classes

Use contextual classes to style list items with a stateful background and context.

<Example>
  <CxListGroup>
    <CxListGroupItem>Dapibus ac facilisis in</CxListGroupItem>
    {['primary', 'secondary', 'success', 'danger', 'warning', 'info'].map(
      (context, index) => (
        <CxListGroupItem context={context} key={index}>
          A simple {context} list group item
        </CxListGroupItem>
      ),
    )}
  </CxListGroup>
</Example>

```jsx
<CxListGroup>
  <CxListGroupItem>Dapibus ac facilisis in</CxListGroupItem>
  {['primary', 'secondary', 'success', 'danger', 'warning', 'info'].map(
    (context, index) => (
      <CxListGroupItem context={context} key={index}>
        A simple {context} list group item
      </CxListGroupItem>
    ),
  )}
</CxListGroup>
```

Contextual classes also work with `<a>`s or `<button>`s. Note the addition of the hover styles here not present in the previous example. Also supported is the `active` state; apply it to indicate an active selection on a contextual list group item.

<Example>
  <CxListGroup>
    <CxListGroupItem component="a" href="#">
      Dapibus ac facilisis in
    </CxListGroupItem>
    {['primary', 'secondary', 'success', 'danger', 'warning', 'info'].map(
      (context, index) => (
        <CxListGroupItem component="a" href="#" context={context} key={index}>
          A simple {context} list group item
        </CxListGroupItem>
      ),
    )}
  </CxListGroup>
</Example>

```jsx
<CxListGroup>
  <CxListGroupItem component="a" href="#">
    Dapibus ac facilisis in
  </CxListGroupItem>
  {['primary', 'secondary', 'success', 'danger', 'warning', 'info'].map(
    (context, index) => (
      <CxListGroupItem component="a" href="#" context={context} key={index}>
        A simple {context} list group item
      </CxListGroupItem>

</CxListGroup>
```
