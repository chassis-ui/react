import { Form, FormLabel, RangeInput } from '@chassis-ui/react'

## Overview

Create custom `<input type="range">` controls with `<RangeInput>`. The track (the background) and thumb (the value) are both styled to appear the same across browsers. As only Edge Legacy and Firefox supports "filling" their track from the left or right of the thumb as a means to visually indicate progress, we do not currently support it.

<Example>
  <FormLabel htmlFor="customRange1">Example range</FormLabel>
  <RangeInput id="customRange1" />
</Example>

## Disabled

Add the `disabled` boolean attribute on an input to give it a grayed out appearance and remove pointer events.

<Example>
  <FormLabel htmlFor="disabledRange">Disabled range</FormLabel>
  <RangeInput id="disabledRange" disabled />
</Example>

## Min and max

Range inputs have implicit values for `min` and `max`—`0` and `100`, respectively. You may specify new values for those using the `min` and `max` attributes.

<Example>
  <FormLabel htmlFor="customRange2">Example range</FormLabel>
  <RangeInput min="0" max="5" defaultValue="3" id="customRange2" />
</Example>

## Steps

By default, range inputs "snap" to integer values. To change this, you can specify a `step` value. In the example below, we double the number of steps by using `step="0.5"`.

<Example>
  <FormLabel htmlFor="customRange3">Example range</FormLabel>
  <RangeInput min="0" max="5" step="0.5" defaultValue="3" id="customRange3" />
</Example>
