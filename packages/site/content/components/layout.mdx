## Forms

Every group of form fields should reside in a `<CxForm>` element. Chassis provides no default styling for the `<CxForm>` element, but there are some powerful browser features that are provided by default.

- New to browser forms? Consider reviewing [the MDN form docs](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/form) for an overview and complete list of available attributes.
- `<CxButton>`s within a `<CxForm>` default to `type="submit"`, so strive to be specific and always include a `type`.
- You can disable every form element within a form with the `disabled` attribute on the `<CxForm>`.

Since Chassis applies `display: block` and `width: 100%` to almost all our form controls, forms will by default stack vertically. Additional classes can be used to vary this layout on a per-form basis.

## Utilities

Margin utilities are the easiest way to add some structure to forms. They provide basic grouping of labels, controls, optional form text, and form validation messaging. We recommend sticking to `margin-bottom` utilities, and using a single direction throughout the form for consistency.

## Form grid

More complex forms can be built using our grid classes. Use these for form layouts that require multiple columns, varied widths, and additional alignment options.

<Example>
  <CxRow>
    <CxCol xs>
      <CxTextInput placeholder="First name" aria-label="First name"/>
    </CxCol>
    <CxCol xs>
      <CxTextInput placeholder="Last name" aria-label="Last name"/>
    </CxCol>
  </CxRow>
</Example>

## Gutters

By adding gutter modifier classes, you can have control over the gutter width in as well the inline as block direction.

<Example>
  <CxRow className="g-3">
    <CxCol xs>
      <CxTextInput placeholder="First name" aria-label="First name"/>
    </CxCol>
    <CxCol xs>
      <CxTextInput placeholder="Last name" aria-label="Last name"/>
    </CxCol>
  </CxRow>
</Example>

## Horizontal form

Create horizontal forms with the grid by adding the `.row` class to form groups and using the `.col-*-*` classes to specify the width of your labels and controls. Be sure to add `.col-form-label` to your `<CxFormLabel>`s as well so they're vertically centered with their associated form controls.

At times, you maybe need to use margin or padding utilities to create that perfect alignment you need.

<Example>
  <HorizontalFormExample client:load />
</Example>

### Horizontal form label sizing

Be sure to use `.col-form-label-small` or `.col-form-label-large` to your `<CxFormLabel>`s or `<legend>`s to correctly follow the size of `.large` and `.small`.

<Example>
  <CxRow className="mb-medium">
    <CxFormLabel htmlFor="colFormLabelSm" className="small:col-2 col-form-label col-form-label-small">Email</CxFormLabel>
    <CxCol sm={10} >
      <CxTextInput type="email" className="form-input small" id="colFormLabelSm" placeholder="col-form-label-small"/>
    </CxCol>
  </CxRow>
  <CxRow className="mb-medium">
    <CxFormLabel htmlFor="colFormLabel" className="small:col-2 col-form-label">Email</CxFormLabel>
    <CxCol sm={10} >
      <CxTextInput type="email" id="colFormLabel" placeholder="col-form-label"/>
    </CxCol>
  </CxRow>
  <CxRow>
    <CxFormLabel htmlFor="colFormLabelLg" className="small:col-2 col-form-label col-form-label-large">Email</CxFormLabel>
    <CxCol sm={10} >
      <CxTextInput type="email" className="form-input large" id="colFormLabelLg" placeholder="col-form-label-large"/>
    </CxCol>
  </CxRow>
</Example>

## Column sizing

As shown in the previous examples, our grid system allows you to place any number of `<CxCol>`s within a `<CxRow>`. They'll split the available width equally between them. You may also pick a subset of your columns to take up more or less space, while the remaining `<CxCol>`s equally split the rest, with specific column classes like `<CxCol sm={7} >`.

<Example>
  <CxRow className="g-3">
    <CxCol sm={7} >
      <CxTextInput placeholder="City" aria-label="City"/>
    </CxCol>
    <CxCol sm>
      <CxTextInput placeholder="State" aria-label="State"/>
    </CxCol>
    <CxCol sm>
      <CxTextInput placeholder="Zip" aria-label="Zip"/>
    </CxCol>
  </CxRow>
</Example>

## Auto-sizing

The example below uses a flexbox utility to vertically center the contents and changes `<CxCol>` to `<CxCol xs="auto">` so that your columns only take up as much space as needed. Put another way, the column sizes itself based on the contents.

<Example>
  <CxForm className="row gy-2 gx-3 align-items-center">
    <CxCol xs="auto">
      <CxFormLabel className="visually-hidden" htmlFor="autoSizingInput">Name</CxFormLabel>
      <CxTextInput id="autoSizingInput" placeholder="Jane Doe"/>
    </CxCol>
    <CxCol xs="auto">
      <CxFormLabel className="visually-hidden" htmlFor="autoSizingInputGroup">Username</CxFormLabel>
      <CxInputGroup>
        <CxInputAddon>@</CxInputAddon>
        <CxTextInput id="autoSizingInputGroup" placeholder="Username"/>
      </CxInputGroup>
    </CxCol>
    <CxCol xs="auto">
      <CxFormLabel className="visually-hidden" htmlFor="autoSizingSelect">Preference</CxFormLabel>
      <CxSelect id="autoSizingSelect">
        <option>Choose...</option>
        <option value="1">One</option>
        <option value="2">Two</option>
        <option value="3">Three</option>
      </CxSelect>
    </CxCol>
    <CxCol xs="auto">
      <CxCheckbox id="autoSizingCheck" label="Remember me"/>
    </CxCol>
    <CxCol xs="auto">
      <CxButton type="submit">Submit</CxButton>
    </CxCol>
  </CxForm>
</Example>

You can then remix that once again with size-specific column classes.

## Inline forms

Use the `<CxCol xs="auto">` class to create horizontal layouts. By adding gutter modifier classes, we will have gutters in horizontal and vertical directions. The `.align-items-center` aligns the form elements to the middle, making the `<CxCheckbox>` align properly.

<Example>
  <CxForm className="row large:row-cols-auto g-3 align-items-center">
    <CxCol xs={12}>
      <CxFormLabel className="visually-hidden" htmlFor="inlineFormInputGroupUsername">Username</CxFormLabel>
      <CxInputGroup>
        <CxInputAddon>@</CxInputAddon>
        <CxTextInput id="inlineFormInputGroupUsername" placeholder="Username"/>
      </CxInputGroup>
    </CxCol>
    <CxCol xs={12}>
      <CxFormLabel className="visually-hidden" htmlFor="inlineFormSelectPref">Preference</CxFormLabel>
      <CxSelect id="inlineFormSelectPref">
        <option>Choose...</option>
        <option value="1">One</option>
        <option value="2">Two</option>
        <option value="3">Three</option>
      </CxSelect>
    </CxCol>
    <CxCol xs={12}>
      <CxCheckbox id="inlineFormCheck" label="Remember me"/>
    </CxCol>
    <CxCol xs={12}>
      <CxButton type="submit">Submit</CxButton>
    </CxCol>
  </CxForm>
</Example>
