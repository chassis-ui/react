## Smart pagination

Pass `pages`, `activePage`, and `onActivePageChange` to let `<Pagination>` render the full control automatically — Prev/Next buttons, page numbers, and ellipsis for large ranges.


<Example>
  <SmartExample client:load />
</Example>

### Max visible pages

Use `maxVisiblePages` to control how many page buttons appear before collapsing to ellipsis (default is `5`).


<Example>
  <MaxVisibleExample client:load />
</Example>

## Manual markup

For full control, compose the pagination using `<Pagination.Item>` directly.

<Example>
  <Pagination aria-label="Page navigation example">
    <Pagination.Item aria-label="Previous">&laquo;</Pagination.Item>
    <Pagination.Item>1</Pagination.Item>
    <Pagination.Item active>2</Pagination.Item>
    <Pagination.Item>3</Pagination.Item>
    <Pagination.Item aria-label="Next">&raquo;</Pagination.Item>
  </Pagination>
</Example>

### Disabled and active states

<Example>
