## Examples

`<CloseButton>` renders a dismiss control for closing a component like a modal or an alert. Its
default styling is minimal — an X icon with no border or background — so it composes cleanly into
whatever surface it sits on.

<Example>
  <BasicExample client:load />
</Example>

## Disabled state

Set `disabled` to lower the button's `opacity` and block interaction. `pointer-events: none` and
`user-select: none` also apply, so hover and active states never trigger.

<Example>
  <DisabledExample client:load />
</Example>

## Sizes

Set `size` to `"small"` or `"large"` to match `<CloseButton>` to surrounding component sizes.

## Contextual colors

`<CloseButton>` inherits its icon color from the nearest context class by default.

`<CloseButton>` renders with an accessible name of "Close" by default. Use the `label` property to localize it for non-English contexts.
