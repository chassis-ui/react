import { ColorInput, FormLabel } from '@chassis-ui/react'

## Overview

`<ColorInput>` wraps `<input type="color">` with the `.form-input` class, giving a consistently sized and rounded color swatch with no additional markup required.

<Example>
  <FormLabel htmlFor="exampleColorInput">Color picker</FormLabel>
  <ColorInput id="exampleColorInput" defaultValue="#0d6efd" />
</Example>

## Disabled

Add the `disabled` boolean attribute to give the input a grayed-out appearance and remove pointer events.

<Example>
  <FormLabel htmlFor="exampleColorInputDisabled">Disabled color picker</FormLabel>
  <ColorInput id="exampleColorInputDisabled" defaultValue="#0d6efd" disabled />
</Example>

## As a form field

Use `label`/`help`/`invalidFeedback`/`validFeedback` directly on `<ColorInput>` to wrap it in a `.form-field` with an associated label and help text.

<Example>
  <ColorInput
    label="Accent color"
    help="Used for links and primary buttons."
    defaultValue="#0d6efd"
    id="accentColor"
  />
</Example>
