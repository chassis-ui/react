## Overview

`Menu` is a toggleable contextual overlay for links, buttons, and inline forms. It replaces the old `CxDropdown` family, is positioned using [React Aria](https://react-spectrum.adobe.com/react-aria/)'s `useOverlayPosition`, and handles keyboard navigation and multi-level submenus. Menus open on click by default.

## Close behavior

The `autoClose` prop controls which clicks close the menu. The default (`true`) closes on any click inside or outside. Use `'inside'` or `'outside'` to restrict to one side, or `false` to require a programmatic `visible` change.

<Example>
  <AutoCloseExample client:load />
</Example>

## Submenus

Wrap a trigger and nested items in `MenuSubmenu` to create a flyout. Submenus close sibling submenus automatically when a new one opens, and close along with their ancestor menu. Set `activation` to `'hover'` or `'click'` to restrict which interaction opens it on hover-capable devices — the default, `'both'`, accepts either; touch devices always use tap regardless of this setting. Which side a submenu cascades toward follows the active locale's direction — see [Internationalization]([[docsref:/getting-started/internationalization#right-to-left]]).

</Example>
