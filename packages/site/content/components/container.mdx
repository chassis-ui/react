## Overview

`<Container>` is the most basic layout element in Chassis, and is **required when using the default grid system**. It contains, pads, and (sometimes) centers the content inside it. Containers can be nested, though most layouts don't need a nested container.

Chassis comes with three container variants:

- `<Container>`, which sets a `max-width` at each responsive breakpoint
- `<Container fluid>`, which is `width: 100%` at all breakpoints
- `<Container fluidUntil={breakpoint}>`, which is `width: 100%` until the specified breakpoint

Each variant's `max-width` follows a different pattern across breakpoints, shown here against the plain `<Container>` and `<Container fluid>` baselines.

## Default container

The default `<Container>` class is a responsive, fixed-width container — its `max-width` changes at each breakpoint.

## Responsive containers

`<Container fluidUntil={breakpoint}>` renders full width until the given breakpoint is reached, then applies a `max-width` at that breakpoint and every larger one. `<Container fluidUntil="small">`, for example, stays 100% wide until the `small` breakpoint, then scales up through `medium`, `large`, `xlarge`, and `2xlarge`.
