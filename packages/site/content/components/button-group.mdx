## Basic example

Wrap a series of `<CxButton>` components in `<CxButtonGroup>`.

<Example>
  <CxButtonGroup role="group" aria-label="Basic example">
    <CxButton context="primary">Left</CxButton>
    <CxButton context="primary">Middle</CxButton>
    <CxButton context="primary">Right</CxButton>
  </CxButtonGroup>
</Example>

##### Ensure the correct `role` and provide a label

For assistive technologies (ex. screen readers) to communicate that a series of buttons are grouped, a proper `role` attribute has to be provided. For button groups, this should be `role="group"`, while toolbars should have a `role="toolbar"`.

Besides, groups and toolbars should be provided an understandable label, as most assistive technologies will otherwise not declare them, despite the appearance of the specific role attribute. In the following examples provided here, we apply `aria-label`, but options such as `aria-labelledby` can also be used.

These classes can also be added to groups of links, as an alternative to the `<CxNav>` components.

<Example>
  <CxButtonGroup>
    <CxButton href="#" context="primary" active>
      Active link
    </CxButton>
    <CxButton href="#" context="primary">
      Link
    </CxButton>
    <CxButton href="#" context="primary">
      Link
    </CxButton>
  </CxButtonGroup>
</Example>

## Checkbox and radio button groups

Combine button-like checkbox and radio toggle buttons into a seamless looking button group.

## Button toolbar

Join sets of button groups into button toolbars for more complicated components. Use utility classes as needed to space out groups, buttons, and more.

<Example>
  <CxButtonToolbar role="group" aria-label="Toolbar with button groups">
    <CxButtonGroup className="me-small" role="group" aria-label="First group">
      <CxButton context="primary">1</CxButton>
      <CxButton context="primary">2</CxButton>
      <CxButton context="primary">3</CxButton>
      <CxButton context="primary">4</CxButton>
    </CxButtonGroup>
    <CxButtonGroup className="me-small" role="group" aria-label="Second group">
      <CxButton context="secondary">5</CxButton>
      <CxButton context="secondary">6</CxButton>
      <CxButton context="secondary">7</CxButton>
    </CxButtonGroup>
    <CxButtonGroup className="me-small" role="group" aria-label="Third group">
      <CxButton context="info">8</CxButton>
    </CxButtonGroup>
  </CxButtonToolbar>
</Example>

Feel free to combine input groups with button groups in your toolbars. Similar to the example above, you'll likely need some utilities through to space items correctly.

<Example>
  <CxButtonToolbar className="mb-medium" role="group" aria-label="Toolbar with button groups">
    <CxButtonGroup className="me-small" role="group" aria-label="First group">

        1

      <CxButton context="secondary" variant="outline">

    <CxInputGroup>

        2

      <CxButton context="secondary" variant="outline">

        4

## Sizing

Alternatively, of implementing button sizing classes to each button in a group, set `size` property to all `<CxButtonGroup>`'s, including each one when nesting multiple groups.

<Example>
  <CxButtonGroup size="large" role="group" aria-label="Large button group">
    <CxButton variant="outline">
      Left
    </CxButton>
    <CxButton variant="outline">
      Middle
    </CxButton>
    <CxButton variant="outline">
      Right
    </CxButton>
