## Overview

A switch has the markup of a custom checkbox but renders as a toggle switch via `<Switch>`. It
supports the native `disabled` attribute, same as any checkbox input.

</Example>

## Sizes

Set `size` to `"sm"` or `"lg"` to change a switch's dimensions; the default renders at
md size.

## Context colors

Set `color` to any of the Chassis context colors to tint the switch indicator when selected.

  <ColorExample client:load />

## One of a group

Set `type="radio"` on switches that share a `name` to keep one of them on at a time, as radios do:
turning one on turns the others off, a click leaves the one that is on, and `required` asks for one
of the group. Each is still a checkbox with `role="switch"`, so the form submits the `value` of the
one that is on.
