## About

A react card component is a content container. It incorporates options for images, headers, and footers, a wide variety of content, contextual background colors, and excellent display options.

## Example

Cards are built with as little markup and styles as possible but still manage to deliver a bunch of control and customization. Built with flexbox, they offer easy alignment and mix well with other Chassis components. Cards have no top, left, and right margins by default, so use spacing utilities as needed. They have no fixed width to start, so they'll fill the full width of its parent.

Below is an example of a basic card with mixed content and a fixed width. Cards have no fixed width to start, so they'll naturally fill the full width of its parent element.

<Example>
  <Card style={{ width: '18rem' }}>
    <CardImage orientation="top" src="https://placehold.co/800x400" />
    <CardBody>
      <CardTitle>Card title</CardTitle>
      <CardText>
        Some quick example text to build on the card title and make up the bulk of the card's
        content.
      </CardText>
      <Button href="#">Go somewhere</Button>
    </CardBody>
  </Card>
</Example>

## Standard cards

For the common case — a single image, a title, some text, maybe a footer — `<Card>` accepts
`image`/`imageAlt`/`imageOrientation`, `title`, `subtitle`, `text`, and `footer` shorthand props
directly, instead of composing `CardImage`/`CardBody`/`CardTitle`/`CardText`/`CardFooter`
yourself. `title`/`subtitle`/`text`/`children` render together inside a single `CardBody`, in that
order, so `children` still works for trailing content like a button. This example produces the
same markup as the one above:

<Example>
  <Card
    style={{ width: '18rem' }}
    image="https://placehold.co/800x400"
    title="Card title"
    text="Some quick example text to build on the card title and make up the bulk of the card's content."
  >
    <Button href="#">Go somewhere</Button>
  </Card>
</Example>

Shorthand props only take effect once at least one of `image`/`title`/`subtitle`/`text`/`footer`
is set — otherwise `children` render exactly as passed, so full manual composition (`CardHeader`,
flush lists, image overlays, nav headers, horizontal layouts, …) keeps working unchanged. Mixing
shorthand props with a manually-composed `children` tree (e.g. a raw `CardHeader`) isn't
supported — pick one approach per card, falling back to composing `CardBody`/`CardTitle`/etc.
directly for anything the shorthand props don't cover.

`image` also accepts a full element instead of a `src` string — a `<CardImage>` composed by hand,
a [`<Placeholder>`]([[docsref:/components/placeholder]]), a loading
[`<Skeleton>`]([[docsref:/components/skeleton]]) — rendered as-is in the image slot, so the rest of
`title`/`subtitle`/`text`/`footer` don't have to give up their shorthand just because the image
needs something other than a plain URL. `imageAlt`/`imageOrientation` only apply to the `src` form;
set them directly on your own element otherwise. See
[Loading states]([[docsref:/patterns/loading-states]]) for a worked example swapping the image for
a skeleton while data loads.

## Content types

Chassis card supports a wide variety of content, including images, text, lists, links, and more. Below are examples of those elements.

### Body

The main block of a card is the `<CardBody>`. Use it whenever you need a padded section within a card.

<Example>
  <Card>
    <CardBody>This is some text within a card body.</CardBody>
  </Card>
</Example>

### Titles, text, and links

Card titles are managed by `<CardTitle>` component. Identically, links are attached and collected next to each other by `<CardLink>` component.

Subtitles are managed by `<CardSubtitle>` component. If the `<CardTitle>` also, the `<CardSubtitle>` items are stored in a `<CardBody>` item, the card title, and subtitle are arranged rightly.

<Example>
  <Card style={{ width: '18rem' }}>
    <CardBody>
      <CardTitle>Card title</CardTitle>
      <CardSubtitle className="mb-medium medium:text-emphasis">Card subtitle</CardSubtitle>
      <CardText>
        Some quick example text to build on the card title and make up the bulk of the card's
        content.
      </CardText>
      <CardText>
        <CardLink href="#">Card link</CardLink>
        <CardLink href="#">Another link</CardLink>
      </CardText>
    </CardBody>
  </Card>
</Example>

### Images

`orientation="top"` places a picture to the top of the card. With `<CardText>`, text can be added to the card. Text within `<CardText>` can additionally be styled with the regular HTML tags.

<Example>
  <Card style={{ width: '18rem' }}>
    <CardImage orientation="top" src="https://placehold.co/800x400" />
    <CardBody>
      <CardText>
        Some quick example text to build on the card title and make up the bulk of the card's
        content.
      </CardText>
    </CardBody>
  </Card>
</Example>

`<CardImage>` renders an `<img>` by default, but its `component` prop accepts any element or
component — including a framework's own `Image` (Next.js, Gatsby, Remix, etc.). Whatever you pass
is fully type-checked at the call site, so a component's own props (`fill`, `priority`, `loader`,
and so on) are available and validated alongside `src`/`alt`:

```tsx
import Image from 'next/image'

<CardImage component={Image} src="/hero.jpg" alt="" fill priority orientation="top" />
```

## Horizontal

Set `direction="row"` (or `responsive` for a breakpoint-gated switch) on `<Card>` to lay it out
side-by-side instead of stacked. Wrap the image and body in `<Col>` to control each side's width,
and pair `orientation="top"` with a `responsive` override on `<CardImage>` so the image's rounded
corners switch from the top edge to the start edge at the same breakpoint the card switches to a
row.

<Example>
  <Card responsive={{ large: 'row' }}>
    <Col responsive={{ large: { span: 4 } }}>
      <CardImage
        orientation="top"
        responsive={{ large: 'start' }}
        src="https://placehold.co/800x400"
        style={{ height: '100%', objectFit: 'cover' }}
      />
    </Col>
    <Col responsive={{ large: { span: 8 } }}>
      <CardBody>
        <CardTitle>Card title</CardTitle>
        <CardText>
          This is a wider card with supporting text below as a natural lead-in to additional
          content. This content is a little bit longer.
        </CardText>
        <CardText>
          <small className="fg-subtle">Last updated 3 mins ago</small>
        </CardText>
      </CardBody>
    </Col>
  </Card>
</Example>

To place the image inside a padded body region instead of flush against the card edge, apply
`direction`/`responsive` to `<CardBody>` itself and nest a second `<CardBody className="p-0">` for
the text side so it doesn't get double padding.

<Example>
  <Card>
    <CardBody responsive={{ large: 'row' }} gap="medium">
      <Col responsive={{ large: { span: 4 } }}>
        <CardImage src="https://placehold.co/800x400" />
      </Col>
      <Col responsive={{ large: { span: 8 } }}>
        <CardBody className="p-0">
          <CardTitle>Card title</CardTitle>
          <CardText>
            This is a wider card with supporting text below as a natural lead-in to additional
            content. This content is a little bit longer.
          </CardText>
          <CardText className="mb-0">
            <small className="fg-subtle">Last updated 3 mins ago</small>
          </CardText>
        </CardBody>
      </Col>
    </CardBody>
  </Card>
</Example>

## Card styles

Cards include various options for customizing their backgrounds, borders, and context.

### Context colors

Set `color` to one of the Chassis context colors, and `variant` to `solid`, `smooth`, or `outline`
to control the intensity — omit `variant` for the default (a tinted border and heading, matching
the `basic` chassis-css style).

    {['primary', 'secondary', 'neutral', 'success', 'danger', 'warning', 'info'].map(

              Some quick example text to build on the card title and make up the bulk of the
              card's content.

  </>
</Example>

<Example>
