### Controlled

A composed `AccordionItem` already supports the native controlled `<details>` pattern directly —
pass `open` and read the new state back from `onToggle`:

```tsx
<AccordionItem open={isOpen} onToggle={(e) => setIsOpen(e.currentTarget.open)}>
```

For the `items` data-driven API, `Accordion` offers the same thing at the group level:
`expandedKeys`/`defaultExpandedKeys`/`onExpandedChange` track which item keys are open, reflecting
the native `<details>` elements' actual state (including any the browser closes itself as part of
a shared `name` group).
