React toasts are lightweight notifications designed to mimic the push notifications that have been popularized by mobile and desktop operating systems. They're built with flexbox, so they're easy to align and position.

## Overview

Things to know when using the toast plugin:

- Toasts are opt-in — nothing renders until you flip `visible` to `true` (directly, or via `CxToaster`'s `push` prop).
- Toasts will automatically hide after `delay` milliseconds unless you set `autohide={false}`. The countdown pauses while the pointer is over the toast or focus is within it, and only resumes once both leave.
- Use `role="status"` (the default) for routine confirmations and informational updates. Reserve `role="alert"` for errors and messages requiring immediate attention. Both roles carry implicit live-region semantics, so no separate `aria-live` prop is needed.

## Examples

### Basic

To encourage extensible and predictable toasts, we recommend a header and body. Toast headers use `display: flex`, allowing easy alignment of content thanks to our margin and flexbox utilities.

Toasts are as flexible as you need and have very little required markup. At a minimum, we require a single element to contain your "toasted" content and strongly encourage a dismiss button.

<Example>
  <CxToast client:load animation={false} autohide={false} visible={true}>
    <CxToastHeader closeButton>
      <svg
        className="rounded me-small"
        width="20"
        height="20"
        xmlns="http://www.w3.org/2000/svg"
        preserveAspectRatio="xMidYMid slice"
        focusable="false"
        role="img"
      >
        <rect width="100%" height="100%" fill="#007aff"></rect>
      </svg>
      <strong className="me-auto">Chassis</strong>
      <small>7 min ago</small>
    </CxToastHeader>
    <CxToastBody>Hello, world! This is a toast message.</CxToastBody>
  </CxToast>
</Example>

### Action footer

Add a `CxToastFooter` below the body to hold acknowledgement or follow-up actions. It renders `.toast-footer`, separated from the body by a border that matches the header rule.

<Example>
  <CxToast client:load autohide={false} visible={true}>
    <CxToastBody>Hello, world! This is a toast message.</CxToastBody>
    <CxToastFooter>
      <CxButton type="button" context="primary" size="small">
        Take action
      </CxButton>
      <CxToastClose component={CxButton} context="secondary" size="small">
        Close
      </CxToastClose>
    </CxToastFooter>
  </CxToast>
</Example>

You can stack toasts by wrapping them in a `CxToaster`, which will vertically add some spacing between them.

### Simplified layout

Customize your toasts by removing sub-components, tweaking them with utilities, or by adding your own markup. Here we've created a simpler toast by removing the default `<CxToastHeader>`, adding a custom hide icon from Chassis Icons, and using some flexbox utilities to adjust the layout.

<Example>
  <CxToast client:load autohide={false} visible={true} className="align-items-center">
    <div className="d-flex">
      <CxToastBody>Hello, world! This is a toast message.</CxToastBody>
      <CxToastClose className="me-small m-auto" />
    </div>
  </CxToast>
</Example>

### Color schemes

Apply `context` and add `solid` for a full-color background with inverted text. Here we've set `context="primary"` and `solid` on the `<CxToast>`.

<Example>
  <CxToast client:load autohide={false} visible={true} context="primary" solid className="align-items-center">
    <div className="d-flex">
      <CxToastBody>Hello, world! This is a toast message.</CxToastBody>
      <CxToastClose className="me-small m-auto" />
    </div>
  </CxToast>
</Example>
