## Overview

`CxCalendar` is a single-month date grid with keyboard-navigable cells, usable on its own wherever an inline calendar is needed — no popover, no text field. [`CxDatePicker`](/forms/datepicker) renders this same component inside its popover, so the two always look and behave identically.

## Min & max dates

Restrict the selectable range with `minValue`/`maxValue`. Dates outside the range are shown but disabled.

## Unavailable dates

Pass `isDateUnavailable` to mark specific dates as unselectable without excluding them from the grid — useful for booked dates, holidays, or (as below, using `@internationalized/date`'s locale-aware `isWeekend`) weekends. Unavailable dates remain focusable so screen reader users can discover why they can't be picked.

<Example>
  <UnavailableExample client:load />
</Example>

### From a list of dates

For data-driven cases — booked dates fetched from an API, say — pass `unavailableDates` instead: a plain array of ISO 8601 (`YYYY-MM-DD`) strings. It composes with `isDateUnavailable` when both are given; a date unavailable by either is unavailable.

</Example>

## Weekend styling

Saturday/Sunday (or whichever days the active locale considers the weekend — determined via `@internationalized/date`'s `isWeekend`) are shown muted automatically, no prop required. This is purely visual — weekends stay selectable unless also marked unavailable. Every example on this page shows it.

## Navigation

By default, `CxCalendar` shows month and year `<select>`s next to the prev/next buttons, for jumping further than one page at a time. Pass `navigation="arrows"` for the plain prev/next-only header instead.

## Accessible name

`CxCalendar` has no visible label of its own — pass `aria-label` or `aria-labelledby` any time it's used standalone (as in every example above). When composed inside `CxDatePicker`'s popover, the accessible name instead comes from the picker's own label.

## Scope

- **Single month** — the grid always shows one month at a time; multi-month display isn't supported yet.
- **Single date** — one selected date at a time; for range selection, see [`CxRangeCalendar`](/forms/range-calendar).

## Styling

Like `CxDatePicker`, `CxCalendar` isn't styled by `@chassis-ui/css` — chassis-css's own datepicker styling is built entirely around [Vanilla Calendar Pro](https://vanilla-calendar.pro/)'s specific DOM output, which React Aria's calendar hooks don't produce. `CxCalendar` instead ships its own scoped CSS (built on `@chassis-ui/tokens`' public design tokens, so it still matches the current theme and light/dark mode) that's automatically injected the first time the component is imported — no separate stylesheet to add.
