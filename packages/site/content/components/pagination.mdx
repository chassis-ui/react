## Smart pagination

Pass `pages`, `activePage`, and `onActivePageChange` to let `<Pagination>` render the full control automatically — Prev/Next buttons, page numbers, and ellipsis for large ranges.


<Example>
  <SmartExample client:load />
</Example>

### Max visible pages

Use `maxVisiblePages` to control how many page buttons appear before collapsing to ellipsis (default is `5`).


<Example>
  <MaxVisibleExample client:load />
</Example>

## Manual markup

For full control, compose the pagination using `<PaginationItem>` directly.

<Example>
  <Pagination aria-label="Page navigation example">
    <PaginationItem aria-label="Previous">&laquo;</PaginationItem>
    <PaginationItem>1</PaginationItem>
    <PaginationItem active>2</PaginationItem>
    <PaginationItem>3</PaginationItem>
    <PaginationItem aria-label="Next">&raquo;</PaginationItem>
  </Pagination>
</Example>

### Disabled and active states

<Example>
  <Pagination aria-label="...">
    <PaginationItem disabled>&laquo;</PaginationItem>
    <PaginationItem active>1</PaginationItem>
