## Key points

- Stat cards use `<CxBadge>` for delta indicators — the `context` prop drives the color semantically.
- The orders table uses a `render` function to replace raw status strings with `<CxBadge>` components.
- `<CxList flush items={...} />` renders a borderless activity feed from a plain array.
- Progress bars take `context` directly; `value` and `max` work like the native `<progress>` element.
