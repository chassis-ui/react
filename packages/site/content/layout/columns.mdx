import { Col, Container, Row } from '@chassis-ui/react'

## How they work

- **Columns build on the grid's flexbox architecture.** Flexbox means we have options for changing individual columns and [modifying groups of columns at the row level](./row#row-columns). You choose how columns grow, shrink, or otherwise change.

- **When building grid layouts, all content goes in columns.** The hierarchy of Chassis grid goes from [container](./containers) to row to column to your content. On rare occasions, you may combine content and column, but be aware there can be unintended consequences.

- **Chassis includes predefined components for creating fast, responsive layouts.** With [six breakpoints](./breakpoints) and a dozen columns at each grid tier, we have dozens of components already built for you to create your desired layouts. This can be disabled via Sass if you wish.

### Column wrapping

If more than 12 columns are placed within a single row, each group of extra columns will, as one unit, wrap onto a new line.

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col span={9}>.col-9</Col>
      <Col span={4}>
        .col-4
        <br />
        Since 9 + 4 = 13 &gt; 12, this 4-column-wide div gets wrapped onto a new line as one
        contiguous unit.
      </Col>
      <Col span={6}>
        .col-6
        <br />
        Subsequent columns continue along the new line.
      </Col>
    </Row>
  </Container>
</Example>

### Column breaks

Breaking columns to a new line in flexbox requires a small hack: add an element with `width: 100%` wherever you want to wrap your columns to a new line. Normally this is accomplished with multiple `<Row>`s, but not every implementation method can account for this.

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col span={6} responsive={{ small: { span: 3 } }}>
        .col-6 .small:col-3
      </Col>
      <Col span={6} responsive={{ small: { span: 3 } }}>
        .col-6 .small:col-3
      </Col>
      <div className="w-100"></div>
      <Col span={6} responsive={{ small: { span: 3 } }}>
        .col-6 .small:col-3
      </Col>
      <Col span={6} responsive={{ small: { span: 3 } }}>
        .col-6 .small:col-3
      </Col>
    </Row>
  </Container>
</Example>

You may also apply this break at specific breakpoints with our responsive display utilities.

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col span={6} responsive={{ small: { span: 4 } }}>
        .col-6 .small:col-4
      </Col>
      <Col span={6} responsive={{ small: { span: 4 } }}>
        .col-6 .small:col-4
      </Col>
      <div className="w-100 d-none medium:d-block"></div>
      <Col span={6} responsive={{ small: { span: 4 } }}>
        .col-6 .small:col-4
      </Col>
      <Col span={6} responsive={{ small: { span: 4 } }}>
        .col-6 .small:col-4
      </Col>
    </Row>
  </Container>
</Example>

## Reordering

### Order props

Use `order` (or `responsive={{ {breakpoint}: { order: 1-5 } }}` for overrides) to control the **visual order** of your content. These props are responsive, so you can set the `order` by breakpoint (e.g., `order={1}` with `responsive={{ medium: { order: 2 } }}`). Includes support for `1` through `5` across all six grid tiers.

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col>First in DOM, no order applied</Col>
      <Col span order={5}>Second in DOM, with a larger order</Col>
      <Col span order={1}>Third in DOM, with an order of 1</Col>
    </Row>
  </Container>
</Example>

There are also `order="first"` and `order="last"` values that change the `order` of an element by applying `order: -1` and `order: 6`, respectively. These values can also be intermixed with the numbered `order={1-5}` values as needed.

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col span order="last">First in DOM, ordered last</Col>
      <Col>Second in DOM, unordered</Col>
      <Col span order="first">Third in DOM, ordered first</Col>
    </Row>
  </Container>
</Example>

### Offsetting columns

You can offset grid columns in two ways: our responsive `offset` grid prop (`0-12`, or `responsive={{ {breakpoint}: { offset: 0-12 } }}` for overrides) and our margin utilities. Grid props are sized to match columns while margins are more useful for quick layouts where the width of the offset is variable.

#### Offset prop

Move columns to the right using `responsive={{ {breakpoint}: { offset: * } }}` overrides. These increase the left margin of a column by `*` columns. For example, `responsive={{ medium: { offset: 4 } }}` moves `.medium:col-4` over four columns.

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col responsive={{ medium: { span: 4 } }}>.medium:col-4</Col>
      <Col responsive={{ medium: { span: 4, offset: 4 } }}>.medium:col-4 .medium:offset-4</Col>
    </Row>
    <Row>
      <Col responsive={{ medium: { span: 3, offset: 3 } }}>.medium:col-3 .medium:offset-3</Col>
      <Col responsive={{ medium: { span: 3, offset: 3 } }}>.medium:col-3 .medium:offset-3</Col>
    </Row>
    <Row>
      <Col responsive={{ medium: { span: 6, offset: 3 } }}>.medium:col-6 .medium:offset-3</Col>
    </Row>
  </Container>
</Example>

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col responsive={{ small: { span: 5 }, medium: { span: 6 } }}>
        .small:col-5 .medium:col-6
      </Col>
      <Col responsive={{ small: { span: 5, offset: 2 }, medium: { span: 6, offset: 0 } }}>
        .small:col-5 .small:offset-2 .medium:col-6 .medium:offset-0
      </Col>
    </Row>
    <Row>
      <Col responsive={{ small: { span: 6 }, medium: { span: 5 }, large: { span: 6 } }}>
        .small:col-6 .medium:col-5 .large:col-6
      </Col>
      <Col
        responsive={{
          small: { span: 6 },
          medium: { span: 5, offset: 2 },
          large: { span: 6, offset: 0 }
        }}
      >
        .small:col-6 .medium:col-5 .medium:offset-2 .large:col-6 .large:offset-0
      </Col>
    </Row>
  </Container>
</Example>

#### Margin utilities

You can use margin utilities like `.me-auto` to force sibling columns away from one another.

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col responsive={{ medium: { span: 4 } }}>.medium:col-4</Col>
      <Col responsive={{ medium: { span: 4 } }} className="ms-auto">
        .medium:col-4 .ms-auto
      </Col>
    </Row>
    <Row>
      <Col responsive={{ medium: { span: 3 } }} className="medium:ms-auto">
        .medium:col-3 .medium:ms-auto
      </Col>
      <Col responsive={{ medium: { span: 3 } }} className="medium:ms-auto">
        .medium:col-3 .medium:ms-auto
      </Col>
    </Row>
    <Row>
      <Col span="auto" className="me-auto">
        .col-auto .me-auto
      </Col>
      <Col span="auto">.col-auto</Col>
    </Row>
  </Container>
</Example>

## Standalone column component

The `<Col>` component can also be used outside a `<Row>` to give an element a specific width. Whenever column component are used as non direct children of a row, the paddings are omitted.

<Example>
  <Col span={3} className="bg-light p-3 border">
    .col-3: width of 25%
  </Col>
  <Col responsive={{ small: { span: 9 } }} className="bg-light p-3 border">
    .small:col-9: width of 75% above sm breakpoint
  </Col>
</Example>
