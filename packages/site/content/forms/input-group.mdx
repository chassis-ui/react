## Basic example

Place one add-on or button on either side of an input. You may also place one on both sides of an input. Remember to place `<CxFormLabel>`s outside the input group.

<Example class="vstack gap-medium">
  <CxInputGroup className="mb-medium">
    <CxInputAddon id="basic-addon1">@</CxInputAddon>
    <CxTextInput placeholder="Username" aria-label="Username" aria-describedby="basic-addon1"/>
  </CxInputGroup>

  <CxInputGroup className="mb-medium">
    <CxTextInput
      placeholder="Recipient's username"
      aria-label="Recipient's username"
      aria-describedby="basic-addon2"
    />
    <CxInputAddon id="basic-addon2">@example.com</CxInputAddon>
  </CxInputGroup>

  <CxFormLabel htmlFor="basic-url">Your vanity URL</CxFormLabel>
  <CxInputGroup className="mb-medium">
    <CxInputAddon id="basic-addon3">https://example.com/users/</CxInputAddon>
    <CxTextInput id="basic-url" aria-describedby="basic-addon3" />
  </CxInputGroup>

  <CxInputGroup className="mb-medium">
    <CxInputAddon>$</CxInputAddon>
    <CxTextInput aria-label="Amount (to the nearest dollar)" />
    <CxInputAddon>.00</CxInputAddon>
  </CxInputGroup>

  <CxInputGroup className="mb-medium">
    <CxTextInput placeholder="Username" aria-label="Username" />
    <CxInputAddon>@</CxInputAddon>
    <CxTextInput placeholder="Server" aria-label="Server" />
  </CxInputGroup>

  <CxInputGroup>
    <CxInputAddon>With textarea</CxInputAddon>
    <CxTextarea aria-label="With textarea"></CxTextarea>
  </CxInputGroup>
</Example>

## Wrapping

Input groups wrap by default via `flex-wrap: wrap` in order to accommodate custom form field validation within an input group. You may disable this with `.flex-nowrap`.

<Example>
  <CxInputGroup className="flex-nowrap">
    <CxInputAddon id="addon-wrapping">@</CxInputAddon>
    <CxTextInput placeholder="Username" aria-label="Username" aria-describedby="addon-wrapping" />
  </CxInputGroup>
</Example>

## Sizing

Add the relative form sizing classes to the `<CxInputGroup>` itself and contents within will automatically resize—no need for repeating the form control size classes on each element.

**Sizing on the individual input group elements isn't supported.**

<Example>
  <CxInputGroup size="small" className="mb-medium">
    <CxInputAddon id="inputGroup-sizing-small">Small</CxInputAddon>
    <CxTextInput aria-label="Sizing example input" aria-describedby="inputGroup-sizing-small"/>
  </CxInputGroup>

  <CxInputGroup className="mb-medium">
    <CxInputAddon id="inputGroup-sizing-default">Default</CxInputAddon>
    <CxTextInput aria-label="Sizing example input" aria-describedby="inputGroup-sizing-default" />
  </CxInputGroup>

  <CxInputGroup size="large">
    <CxInputAddon id="inputGroup-sizing-large">Large</CxInputAddon>
    <CxTextInput aria-label="Sizing example input" aria-describedby="inputGroup-sizing-large"/>
  </CxInputGroup>
</Example>

## Multiple inputs

While multiple `<CxTextInput>`s are supported visually, validation styles are only available for input groups with a single `<CxTextInput>`.

<Example>
  <CxInputGroup>
    <CxInputAddon>First and last name</CxInputAddon>
    <CxTextInput aria-label="First name" />
    <CxTextInput aria-label="Last name" />
  </CxInputGroup>
</Example>

## Multiple addons

Multiple add-ons are supported and can be mixed with checkbox and radio input versions.

<Example>
  <CxInputGroup className="mb-medium">
    <CxInputAddon>$</CxInputAddon>
    <CxInputAddon>0.00</CxInputAddon>
    <CxTextInput aria-label="Dollar amount (with dot and two decimal places)"/>
  </CxInputGroup>

  <CxInputGroup>
    <CxTextInput aria-label="Dollar amount (with dot and two decimal places)"/>
    <CxInputAddon>$</CxInputAddon>
    <CxInputAddon>0.00</CxInputAddon>
  </CxInputGroup>
</Example>

## Custom forms

Input groups include support for custom selects and custom file inputs. Browser default versions of these are not supported.

### Custom select

<Example>
  <CxInputGroup className="mb-medium">
    <CxInputAddon component="label" htmlFor="inputGroupSelect01">Options</CxInputAddon>
    <CxSelect id="inputGroupSelect01">
      <option>Choose...</option>
      <option value="1">One</option>
      <option value="2">Two</option>
      <option value="3">Three</option>
    </CxSelect>
  </CxInputGroup>

  <CxInputGroup className="mb-medium">
    <CxSelect id="inputGroupSelect02">
      <option>Choose...</option>
      <option value="1">One</option>
      <option value="2">Two</option>
      <option value="3">Three</option>
    </CxSelect>
    <CxInputAddon component="label" htmlFor="inputGroupSelect02">
      Options
    </CxInputAddon>
  </CxInputGroup>

  <CxInputGroup className="mb-medium">
    <CxButton type="button" context="secondary" variant="outline">
      Button
    </CxButton>
    <CxSelect id="inputGroupSelect03" aria-label="Example select with button addon">
      <option>Choose...</option>
      <option value="1">One</option>
      <option value="2">Two</option>
      <option value="3">Three</option>
    </CxSelect>
  </CxInputGroup>

  <CxInputGroup>
    <CxSelect id="inputGroupSelect04" aria-label="Example select with button addon">
      <option>Choose...</option>
      <option value="1">One</option>
      <option value="2">Two</option>
      <option value="3">Three</option>
    </CxSelect>
    <CxButton type="button" context="secondary" variant="outline">Button</CxButton>
  </CxInputGroup>
</Example>
