## Smart pagination

Pass `pages`, `activePage`, and `onActivePageChange` to let `<CxPagination>` render the full control automatically — Prev/Next buttons, page numbers, and ellipsis for large ranges.


<Example>
  <SmartExample client:load />
</Example>

### Max visible pages

Use `maxVisiblePages` to control how many page buttons appear before collapsing to ellipsis (default is `5`).


<Example>
  <MaxVisibleExample client:load />
</Example>

## Manual markup

For full control, compose the pagination using `<CxPaginationItem>` directly.

<Example>
  <CxPagination aria-label="Page navigation example">
    <CxPaginationItem aria-label="Previous">&laquo;</CxPaginationItem>
    <CxPaginationItem>1</CxPaginationItem>
    <CxPaginationItem active>2</CxPaginationItem>
    <CxPaginationItem>3</CxPaginationItem>
    <CxPaginationItem aria-label="Next">&raquo;</CxPaginationItem>
  </CxPagination>
</Example>

### Disabled and active states

<Example>
  <CxPagination aria-label="...">
