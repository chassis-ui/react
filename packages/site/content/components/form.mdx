## Overview

Chassis form controls expand on Rebooted native form styles with classes, opting into consistent
rendering across browsers and devices.

Set an appropriate `type` attribute on every input (e.g., `email` for an email address, `number`
for numerical information) to take advantage of the browser's native input controls, like email
verification and number selection.

A form combining a labeled email input, a password input, and a checkbox demonstrates the base
building blocks. A `<TextInput>` renders its own `<FormLabel>` and `<FormHelp>` from `label` and
`help`, already associated with the input, and a `<Checkbox>` its own label.

## Form text

`<FormHelp>` renders block-level or inline-level help text alongside a form control. Point the
control's `aria-describedby` at the same id as the `<FormHelp>` so assistive technology — screen
readers in particular — announces the help text when the control receives focus.

A `<TextInput>` beside a `<FormLabel>` written by hand takes the label's `id` as `aria-labelledby`,
as well as the `id` the label's `htmlFor` names: see
[Manual id wiring]([[docsref:/components/form-field#manual-id-wiring]]).

A block-level `<FormHelp>` gets a top margin for spacing from the input above it.

An inline `<FormHelp>` renders as any typical inline element (`component="span"`, or similar) with
just the `.form-help` class applied.

## Disabled forms

Add the `disabled` boolean attribute on an input to prevent interaction and render it with a
lighter appearance:

```jsx
<TextInput type="text" placeholder="Disabled input here..." disabled />
```

Add `disabled` to a `<fieldset>` to disable every control within it. Browsers treat native form
controls (`<input>`, `<select>`, `<button>`) inside a `<fieldset disabled>` as disabled, blocking
both keyboard and mouse interaction.

A custom button-like element such as `<Button>` inside a disabled fieldset only receives
`pointer-events: none` styling, so it stays focusable and operable via keyboard. Add `tabindex="-1"`
to remove it from the tab order and `aria-disabled="true"` to signal its state to assistive
technology.
