Add `Flex`, a general-purpose flexbox container component wrapping `.d-flex`/`.d-inline-flex` and chassis-css's flex utility classes (`direction`, `wrap`, `justify`, `align`, `alignContent`, `gap`/`rowGap`/`columnGap`), including a `responsive` prop for overriding any of these at specific breakpoints via viewport media queries.

Complements `Stack`: reach for `Stack` for simple one-dimensional arrangements with opinionated alignment defaults, `Flex` when you need wrapping, main-axis justification, per-axis gap control, responsive overrides, or no default alignment at all.
