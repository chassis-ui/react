## Key points

- Stat cards use `<Badge>` for delta indicators — the `color` prop drives the color semantically.
- The orders table uses a `render` function to replace raw status strings with `<Badge>` components.
- `<List flush items={...} />` renders a borderless activity feed from a plain array.
- Progress bars take `color` directly; `value` and `max` work like the native `<progress>` element.
