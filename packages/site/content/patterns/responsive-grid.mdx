## Example

Chassis grid system uses a series of containers, rows, and columns to layout and align content. It's built with [flexbox](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Flexible_Box_Layout/Basic_Concepts_of_Flexbox) and is fully responsive. Below is an example and an in-depth explanation for how the grid system comes together.

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col responsive={{ small: { span: 'auto' } }}>One of three columns</Col>
      <Col responsive={{ small: { span: 'auto' } }}>One of three columns</Col>
      <Col responsive={{ small: { span: 'auto' } }}>One of three columns</Col>
    </Row>
  </Container>
</Example>

The above example creates three equal-width columns across all devices and viewports using our predefined grid classes. Those columns are centered in the page with the parent `<Container>`.

## Choosing a layout primitive

This flexbox grid isn't the only layout system available — two others cover cases it isn't the best fit for:

- **[`<Stack>`]([[docsref:/components/stack]])** for simple one-dimensional arrangements (a single row or column of items, like a button toolbar or a form's field list) — no `<Container>`/`<Row>`/`<Col>` nesting required.
- **[`<Grid>`]([[docsref:/components/grid]])** (native CSS Grid) for two-dimensional layouts needing explicit row _and_ column placement, or gutters without the negative-margin technique this flexbox grid relies on.

Reach for `<Row>`/`<Col>`/`<Container>` when you need this system's responsive column-span props, offsets, and ordering — most existing layouts and forms already use it.

## How it works

Breaking it down, here's how the grid system comes together:

- **Our grid supports [six responsive breakpoints](https://chassis-ui.com/css/docs/layout/breakpoints).** Breakpoints are based on `min-width` media queries, meaning they affect that breakpoint and all those above it (e.g., `responsive={{ small: { span: 4 } }}` applies to `small` and every breakpoint above it). This means you can control container and column sizing and behavior by each breakpoint.

- **Containers center and horizontally pad your content.** Use `<Container>` for a responsive pixel width, `<Container fluid>` for `width: 100%` across all viewports and devices, or a responsive container (e.g., `<Container fluidUntil="medium">`) for a combination of fluid and pixel widths.

- **Rows are wrappers for columns.** Each column has horizontal `padding` (called a gutter) for controlling the space between them. This `padding` is then counteracted on the rows with negative margins to ensure the content in your columns is visually aligned down the left side. [`<Row>`]([[docsref:/components/row]]) also supports [uniformly sizing its columns]([[docsref:/components/row#row-columns]]) and [gutter overrides](#gutters) to change the spacing of your content.

- **Columns are incredibly flexible.** There are 12 template columns available per row, allowing you to create different combinations of elements that span any number of columns. The `span` prop indicates the number of template columns to span (e.g., `<Col span={4}>` spans four). `width`s are set in percentages so you always have the same relative sizing.

- **Gutters are also responsive and customizable.** [Gutter classes are available](#gutters) across all breakpoints, with all the same sizes as our margin and padding spacing. Change horizontal gutters with the `gutterX` prop, vertical gutters with `gutterY`, or all gutters with `gutter` — each also available inside `responsive={{ {breakpoint}: { ... } }}` for breakpoint-specific overrides. `gutter={0}` is also available to remove gutters.

Be aware of the limitations and [bugs around flexbox](https://github.com/philipwalton/flexbugs), like the [inability to use some HTML elements as flex containers](https://github.com/philipwalton/flexbugs#flexbug-9).

## Auto-layout columns

Utilize breakpoint-specific column props for easy column sizing without an explicit numbered span like `<Col responsive={{ small: { span: 6 } }}>`.

### Equal-width

For example, here are two grid layouts that apply to every device and viewport, from `xs` to `xxl`. Add `<Col>` for each breakpoint you need and every column will be the same width.

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col>1 of 2</Col>
      <Col>2 of 2</Col>
    </Row>
    <Row>
      <Col>1 of 3</Col>
      <Col>2 of 3</Col>
      <Col>3 of 3</Col>
    </Row>
  </Container>
</Example>

### Setting one column width

Auto-layout for flexbox grid columns also means you can set the width of one column and have the sibling columns automatically resize around it. You may use `span` (as shown below), grid mixins, or inline widths. Note that the other columns will resize no matter the width of the center column.

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col>1 of 3</Col>
      <Col span={6}>2 of 3 (wider)</Col>
      <Col>3 of 3</Col>
    </Row>
    <Row>
      <Col>1 of 3</Col>
      <Col span={6}>2 of 3 (wider)</Col>
      <Col>3 of 3</Col>
    </Row>
  </Container>
</Example>

### Variable width content

Use `span="auto"` (or `responsive={{ {breakpoint}: { span: 'auto' } }}`) to size columns based on the natural width of their content.

<Example className="docs-example-row">
  <Container>
    <div className="row medium:justify-content-center">
      <Col span responsive={{ large: { span: 2 } }}>
        1 of 3
      </Col>
      <Col responsive={{ medium: { span: 'auto' } }}>Variable width content</Col>
      <Col span responsive={{ large: { span: 2 } }}>
        3 of 3
      </Col>
    </div>
    <Row>
      <Col>1 of 3</Col>
      <Col responsive={{ medium: { span: 'auto' } }}>Variable width content</Col>
      <Col span responsive={{ large: { span: 2 } }}>
        3 of 3
      </Col>
    </Row>
  </Container>
</Example>

## Responsive classes

Chassis grid includes six tiers of predefined classes for building complex responsive layouts. Customize the size of your columns on extra small, small, medium, large, or extra large devices however you see fit.

### All breakpoints

For grids that are the same from the smallest of devices to the largest, use the `<Col>` and `<Col span={*}>` classes. Specify a numbered span when you need a particularly sized column; otherwise, feel free to stick to `<Col>`.

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col>col</Col>
      <Col>col</Col>
      <Col>col</Col>
      <Col>col</Col>
    </Row>
    <Row>
      <Col span={8}>col-8</Col>
      <Col span={4}>col-4</Col>
    </Row>
  </Container>
</Example>

### Stacked to horizontal

Using a single `responsive={{ small: { span: * } }}` override, you can create a basic grid system that starts out stacked and becomes horizontal at the small breakpoint (`sm`).

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col responsive={{ small: { span: 8 } }}>small:col-8</Col>
      <Col responsive={{ small: { span: 4 } }}>small:col-4</Col>
    </Row>
    <Row>
      <Col responsive={{ small: { span: true } }}>col-small</Col>
      <Col responsive={{ small: { span: true } }}>col-small</Col>
      <Col responsive={{ small: { span: true } }}>col-small</Col>
    </Row>
  </Container>
</Example>

### Mix and match

Don't want your columns to simply stack in some grid tiers? Use a combination of `span` and `responsive` as needed. See the example below for a better idea of how it all works.

<Example className="docs-example-row">
  <Container>
    <Row>
      <Col responsive={{ medium: { span: 8 } }}>.medium:col-8</Col>
      <Col span={6} responsive={{ medium: { span: 4 } }}>
        .col-6 .medium:col-4
      </Col>
    </Row>
    <Row>
      <Col span={6} responsive={{ medium: { span: 4 } }}>
        .col-6 .medium:col-4
      </Col>
      <Col span={6} responsive={{ medium: { span: 4 } }}>
        .col-6 .medium:col-4
      </Col>
      <Col span={6} responsive={{ medium: { span: 4 } }}>
        .col-6 .medium:col-4
      </Col>
    </Row>
    <Row>
      <Col span={6}>.col-6</Col>
      <Col span={6}>.col-6</Col>
    </Row>
  </Container>
</Example>

### Row columns

Beyond sizing individual `<Col>`s, [`<Row>`'s `cols` prop]([[docsref:/components/row#row-columns]]) uniformly sets the number of columns per row — see the [Row]([[docsref:/components/row]]) page for the full set of examples.

## Gutters

Gutters are the padding between columns, used to responsively space and align content in the grid
system.

- **Gutters are the gaps between column content, created by horizontal `padding`.** `padding-right` and `padding-left` are set on each column, with a negative `margin` offsetting that at the start and end of each row to keep content aligned.
- **Gutters start at `1.5rem` (`24px`) wide.** This matches the grid to the padding and margin spacers scale.
- **Gutters can be responsively adjusted.** Use breakpoint-specific gutter props to modify horizontal gutters, vertical gutters, and all gutters.

### Horizontal

`gutterX` (and `responsive={{ {breakpoint}: { gutterX: * } }}` for overrides) controls the horizontal gutter widths. The `<Container>` or `<Container fluid>` parent may need to be adjusted if larger gutters are used too to avoid unwanted overflow, using a matching padding utility. For example, in the following example the padding is increased with `.px-xlarge`:

<Example>
  <Container className="px-xlarge">
    <Row gutterX="xlarge">
      <Col>
        <div className="border p-medium text-center">Custom column padding</div>
      </Col>
      <Col>
        <div className="border p-medium text-center">Custom column padding</div>
      </Col>
    </Row>
  </Container>
</Example>

An alternative solution is to add a wrapper around the `<Row>` with the `.overflow-hidden` class:

<Example>
  <Container className="overflow-hidden">
    <Row gutterX="xlarge">
      <Col>
        <div className="border p-medium text-center">Custom column padding</div>
      </Col>
      <Col>
        <div className="border p-medium text-center">Custom column padding</div>
      </Col>
    </Row>
  </Container>
</Example>

### Vertical

`gutterY` (and `responsive={{ {breakpoint}: { gutterY: * } }}` for overrides) controls the vertical gutter widths. Like the horizontal gutters, the vertical gutters can cause some overflow below the `<Row>` at the end of a page. If this occurs, add a wrapper around `<Row>` with the `.overflow-hidden` class:

<Example>
  <Container className="overflow-hidden">
    <Row gutterY="xlarge">
      <Col span={6}>
        <div className="border p-medium text-center">Custom column padding</div>
      </Col>
      <Col span={6}>
        <div className="border p-medium text-center">Custom column padding</div>
      </Col>
      <Col span={6}>
        <div className="border p-medium text-center">Custom column padding</div>
      </Col>
      <Col span={6}>
        <div className="border p-medium text-center">Custom column padding</div>
      </Col>
    </Row>
  </Container>
</Example>

### Horizontal and vertical

`gutter` (and `responsive={{ {breakpoint}: { gutter: * } }}` for overrides) controls both horizontal and vertical gutter widths at once; the following example uses a smaller gutter width, so there's no need for the `.overflow-hidden` wrapper class.

<Example>
  <Container>
    <Row gutter="small">
      <Col span={6}>
        <div className="border p-medium text-center">Custom column padding</div>
      </Col>
      <Col span={6}>
        <div className="border p-medium text-center">Custom column padding</div>
      </Col>
      <Col span={6}>
        <div className="border p-medium text-center">Custom column padding</div>
      </Col>
      <Col span={6}>
        <div className="border p-medium text-center">Custom column padding</div>
      </Col>
    </Row>
  </Container>
</Example>

      </Col>

        <div className="border p-medium text-center">Row column</div>

      <Col>
        <div className="border p-medium text-center">Row column</div>

      </Col>
    </Row>
  </Container>
</Example>

### No gutters

The gutters between columns in the predefined grid props can be removed with `gutter={0}`. This removes the negative `margin`s from `<Row>` and the horizontal `padding` from all immediate children columns.

**Need an edge-to-edge design?** Drop the parent `<Container>` or `<Container fluid>`.

In practice, here's how it looks. This continues to work with all other predefined grid props (including column widths, responsive tiers, reorders, and more).

<Example>
  <div className="docs-example-row">
    <Row gutter={0}>
      <Col responsive={{ small: { span: 6 }, medium: { span: 8 } }}>.small:col-6 .medium:col-8</Col>
      <Col span={6} responsive={{ medium: { span: 4 } }}>.col-6 .medium:col-4</Col>
    </Row>
  </div>
</Example>
