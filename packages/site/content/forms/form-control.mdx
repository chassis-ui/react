## Sizing

Set heights using `size` property like `size="large"` and `size="small"`.

<Example>
  <CxFormInput type="text" size="large" placeholder="Large input" aria-label="lg input example"/>
  <br/>
  <CxFormInput type="text" placeholder="Default input" aria-label="default input example"/>
  <br/>
  <CxFormInput type="text" size="small" placeholder="Small input" aria-label="sm input example"/>
</Example>

```jsx
<CxFormInput type="text" size="large" placeholder="Large input" aria-label="lg input example"/>
<CxFormInput type="text" placeholder="Default input" aria-label="default input example"/>
<CxFormInput type="text" size="small" placeholder="Small input" aria-label="sm input example"/>
```

## Disabled

Add the `disabled` boolean attribute on an input to give it a grayed out appearance and remove pointer events.

<Example>
  <CxFormInput type="text" placeholder="Disabled input" aria-label="Disabled input example" disabled/>
  <br/>
  <CxFormInput type="text" placeholder="Disabled readonly input" aria-label="Disabled input example" disabled readOnly/>
  <br/>
</Example>

```jsx
<CxFormInput type="text" placeholder="Disabled input" aria-label="Disabled input example" disabled/>
<CxFormInput type="text" placeholder="Disabled readonly input" aria-label="Disabled input example" disabled readOnly/>
```

## Readonly

Add the `readOnly` boolean attribute on an input to prevent modification of the input's value. Read-only inputs appear lighter (just like disabled inputs), but retain the standard cursor.

<Example>
  <CxFormInput type="text" placeholder="Readonly input here..." aria-label="readonly input example" readOnly/>
</Example>

```jsx
<CxFormInput type="text" placeholder="Readonly input here..." aria-label="readonly input example" readOnly/>
```

## Readonly plain text

If you want to have `<input readonly>` elements in your form styled as plain text, use the `plainText` boolean property to remove the default form field styling and preserve the correct margin and padding.

<Example>
  <CxRow className="mb-3">
    <CxFormLabel htmlFor="staticEmail" className="small:col-2 col-form-label">Email</CxFormLabel>
    <CxCol sm={10}>
      <CxFormInput type="text" id="staticEmail" defaultValue="email@example.com" readOnly plainText/>
    </CxCol>
  </CxRow>
  <CxRow className="mb-3">
    <CxFormLabel htmlFor="inputPassword" className="small:col-2 col-form-label">Password</CxFormLabel>
    <CxCol sm={10}>
      <CxFormInput type="password" id="inputPassword"/>
    </CxCol>
  </CxRow>
</Example>

```jsx
<CxRow className="mb-3">
  <CxFormLabel htmlFor="staticEmail" className="small:col-2 col-form-label">Email</CxFormLabel>
  <CxCol sm={10}>
    <CxFormInput type="text" id="staticEmail" defaultValue="email@example.com" readOnly plainText/>
  </CxCol>
</CxRow>
<CxRow className="mb-3">
  <CxFormLabel htmlFor="inputPassword" className="small:col-2 col-form-label">Password</CxFormLabel>
  <CxCol sm={10}>
    <CxFormInput type="password" id="inputPassword"/>
  </CxCol>
</CxRow>
```
