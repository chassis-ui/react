## Key points

- Validation runs on every render but feedback only shows after the first submit attempt (`submitted` flag).
- `valid` and `invalid` props on inputs add visual state and expose `<FormFeedback>` messages.
- The success `<Notification>` is dismissible — closing it calls `handleReset` which clears all state.
- `noValidate` on `<Form>` disables the browser's built-in validation UI so custom feedback is shown instead.
