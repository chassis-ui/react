## Examples

Use one of the required contextual `color` props (e.g., `primary`) for styling. For inline dismissal, use the [dismissible prop](#dismissing).

<Example>
  <CxNotification color="primary">
    A simple primary notification—check it out!
  </CxNotification>
  <CxNotification color="secondary">
    A simple secondary notification—check it out!
  </CxNotification>
  <CxNotification color="success">
    A simple success notification—check it out!
  </CxNotification>
  <CxNotification color="danger">
    A simple danger notification—check it out!
  </CxNotification>
  <CxNotification color="warning">
    A simple warning notification—check it out!
  </CxNotification>
  <CxNotification color="info">
    A simple info notification—check it out!
  </CxNotification>
</Example>

<Callout context="info">
  <h5>Conveying meaning to assistive technologies</h5>
  <p>
    Using context to add meaning only provides a visual indication, which will not be conveyed to users of assistive technologies – such as screen readers. Ensure that information denoted by the context is either obvious from the content itself (e.g. the visible text), or is included through alternative means, such as additional text hidden with the <code>.visually-hidden</code> class.
  </p>
</Callout>

### Link context

Use `<CxNotificationLink>` to give matching colored links inside any notification.

<Example>
  <CxNotification color="primary">
    A simple primary notification with <CxNotificationLink href="#">an example link</CxNotificationLink>.
  </CxNotification>
  <CxNotification color="secondary">
    A simple secondary notification with <CxNotificationLink href="#">an example link</CxNotificationLink>.
  </CxNotification>
  <CxNotification color="success">
    A simple success notification with <CxNotificationLink href="#">an example link</CxNotificationLink>.
  </CxNotification>
  <CxNotification color="danger">
    A simple danger notification with <CxNotificationLink href="#">an example link</CxNotificationLink>.
  </CxNotification>
  <CxNotification color="warning">
    A simple warning notification with <CxNotificationLink href="#">an example link</CxNotificationLink>.
  </CxNotification>
  <CxNotification color="info">
    A simple info notification with <CxNotificationLink href="#">an example link</CxNotificationLink>.
  </CxNotification>
</Example>

### Additional content

Notifications can incorporate supplementary components like headings, paragraphs, and dividers.

<Example>
  <CxNotification color="success">
    <CxNotificationHeading tag="h4">Well done!</CxNotificationHeading>
    <p>Aww yeah, you successfully read this important notification message. This example text is going to run a bit longer so that you can see how spacing within a notification works with this kind of content.</p>
    <hr />
    <p className="mb-0">Whenever you need to, be sure to use margin utilities to keep things nice and tidy.</p>
  </CxNotification>
</Example>

### Dismissing

Add the `dismissible` prop to let users close the notification.

<Example>
  <CxNotification
    color="warning"
    dismissible
    onClose={() => {
      alert("Dismissed!");
    }}
  >
    <strong>Go right ahead</strong> and click that dismiss button over there on the right.
  </CxNotification>
</Example>
