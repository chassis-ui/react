## Basic example

Place one add-on or button on either side of an input. You may also place one on both sides of an input. Remember to place `<CxFormLabel>`s outside the input group.

<Example>
  <CxInputGroup className="mb-3">
    <CxInputGroupText id="basic-addon1">@</CxInputGroupText>
    <CxFormInput placeholder="Username" aria-label="Username" aria-describedby="basic-addon1"/>
  </CxInputGroup>

  <CxInputGroup className="mb-3">
    <CxFormInput
      placeholder="Recipient's username"
      aria-label="Recipient's username"
      aria-describedby="basic-addon2"
    />
    <CxInputGroupText id="basic-addon2">@example.com</CxInputGroupText>
  </CxInputGroup>

  <CxFormLabel htmlFor="basic-url">Your vanity URL</CxFormLabel>
  <CxInputGroup className="mb-3">
    <CxInputGroupText id="basic-addon3">https://example.com/users/</CxInputGroupText>
    <CxFormInput id="basic-url" aria-describedby="basic-addon3" />
  </CxInputGroup>

  <CxInputGroup className="mb-3">
    <CxInputGroupText>$</CxInputGroupText>
    <CxFormInput aria-label="Amount (to the nearest dollar)" />
    <CxInputGroupText>.00</CxInputGroupText>
  </CxInputGroup>

  <CxInputGroup className="mb-3">
    <CxFormInput placeholder="Username" aria-label="Username" />
    <CxInputGroupText>@</CxInputGroupText>
    <CxFormInput placeholder="Server" aria-label="Server" />
  </CxInputGroup>

  <CxInputGroup>
    <CxInputGroupText>With textarea</CxInputGroupText>
    <CxFormTextarea aria-label="With textarea"></CxFormTextarea>
  </CxInputGroup>
</Example>

## Wrapping

Input groups wrap by default via `flex-wrap: wrap` in order to accommodate custom form field validation within an input group. You may disable this with `.flex-nowrap`.

<Example>
  <CxInputGroup className="flex-nowrap">
    <CxInputGroupText id="addon-wrapping">@</CxInputGroupText>
    <CxFormInput placeholder="Username" aria-label="Username" aria-describedby="addon-wrapping" />
  </CxInputGroup>
</Example>

```jsx
<CxInputGroup className="flex-nowrap">
  <CxInputGroupText id="addon-wrapping">@</CxInputGroupText>
  <CxFormInput placeholder="Username" aria-label="Username" aria-describedby="addon-wrapping" />
</CxInputGroup>
```

## Sizing

Add the relative form sizing classes to the `<CxInputGroup>` itself and contents within will automatically resize—no need for repeating the form control size classes on each element.

**Sizing on the individual input group elements isn't supported.**

<Example>
  <CxInputGroup size="small" className="mb-3">
    <CxInputGroupText id="inputGroup-sizing-small">Small</CxInputGroupText>
    <CxFormInput aria-label="Sizing example input" aria-describedby="inputGroup-sizing-small"/>
  </CxInputGroup>

  <CxInputGroup className="mb-3">
    <CxInputGroupText id="inputGroup-sizing-default">Default</CxInputGroupText>
    <CxFormInput aria-label="Sizing example input" aria-describedby="inputGroup-sizing-default" />
  </CxInputGroup>

  <CxInputGroup size="large">
    <CxInputGroupText id="inputGroup-sizing-large">Large</CxInputGroupText>
    <CxFormInput aria-label="Sizing example input" aria-describedby="inputGroup-sizing-large"/>
  </CxInputGroup>
</Example>

## Checkboxes and radios

Place any checkbox or radio option within an input group's addon instead of text.

<Example>
  <CxInputGroup className="mb-3">
    <CxInputGroupText>
      <CxFormCheck type="checkbox" value="" aria-label="Checkbox for following text input"/>
    </CxInputGroupText>
    <CxFormInput aria-label="Text input with checkbox"/>
  </CxInputGroup>

  <CxInputGroup>
    <CxInputGroupText>
      <CxFormCheck type="radio" value="" aria-label="Radio button for following text input"/>
    </CxInputGroupText>
    <CxFormInput aria-label="Text input with radio button"/>
  </CxInputGroup>
</Example>

<CxInputGroup className="mb-3">
  <CxInputGroupText>
    <CxFormCheck type="checkbox" value="" aria-label="Checkbox for following text input"/>

## Multiple inputs

While multiple `<CxFormInput>`s are supported visually, validation styles are only available for input groups with a single `<CxFormInput>`.

<Example>
  <CxInputGroup>
    <CxInputGroupText>First and last name</CxInputGroupText>
    <CxFormInput aria-label="First name" />
    <CxFormInput aria-label="Last name" />
  </CxInputGroup>
</Example>

```jsx
<CxInputGroup>
  <CxInputGroupText>First and last name</CxInputGroupText>
  <CxFormInput aria-label="First name" />
  <CxFormInput aria-label="Last name" />
</CxInputGroup>
```

## Multiple addons

Multiple add-ons are supported and can be mixed with checkbox and radio input versions.

<Example>
  <CxInputGroup className="mb-3">
    <CxInputGroupText>$</CxInputGroupText>
    <CxInputGroupText>0.00</CxInputGroupText>
    <CxFormInput aria-label="Dollar amount (with dot and two decimal places)"/>
  </CxInputGroup>

  <CxInputGroup>
    <CxFormInput aria-label="Dollar amount (with dot and two decimal places)"/>
    <CxInputGroupText>$</CxInputGroupText>
    <CxInputGroupText>0.00</CxInputGroupText>
  </CxInputGroup>
</Example>

<CxInputGroup className="mb-3">
