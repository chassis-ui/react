## Approach

Browser default checkboxes are replaced with the help of `<Checkbox>`, for selecting one or several options in a list. It renders the modern, wrapper-based `.check-input` markup nested inside a single `<label>` — passing `label` gives you an accessible, fully-clickable control with no extra markup required.

`<Checkbox>` is built on [React Aria](https://react-spectrum.adobe.com/react-aria/) for full keyboard and screen-reader support. It works standalone, or inside a `<CheckboxGroup>` when you want to manage a set of related checkboxes as a single array of selected values.

## Checks

<Example>
  <Checkbox id="flexCheckDefault" label="Default checkbox" />
  <Checkbox id="flexCheckChecked" label="Checked checkbox" defaultSelected />
</Example>

## Indeterminate

Checkboxes can utilize the `:indeterminate` pseudo-class when manually set via `indeterminate` property.

<Example>
  <Checkbox id="flexCheckIndeterminate" label="Indeterminate checkbox" indeterminate />
</Example>

### Disabled

Add the `disabled` attribute and the associated `<label>`s are automatically styled to match with a lighter context to help indicate the input's state.

<Example>
  <Checkbox label="Disabled checkbox" disabled />
  <Checkbox label="Disabled checked checkbox" defaultSelected disabled />
</Example>

## Default (stacked)

By default, any number of checkboxes that are immediate siblings will be vertically stacked and appropriately spaced.

<Example>
  <Checkbox id="defaultCheck1" label="Default checkbox" />
  <Checkbox id="defaultCheck2" label="Disabled checkbox" disabled />
</Example>

## Inline

Group checkboxes on the same horizontal row by wrapping them with the `d-flex` and `gap-medium` flex utilities.

<Example>
  <div className="d-flex gap-medium">
    <Checkbox id="inlineCheckbox1" value="option1" label="1" />
    <Checkbox id="inlineCheckbox2" value="option2" label="2" />
    <Checkbox id="inlineCheckbox3" value="option3" label="3 (disabled)" disabled />
  </div>
</Example>

## Sizing

Apply the `size` property (`small` or `large`) to change the size of a checkbox.

<Example>
  <Checkbox size="large" id="checkLarge" label="Large checkbox" />
  <Checkbox id="checkMedium" label="Default checkbox" />
  <Checkbox size="small" id="checkSmall" label="Small checkbox" />
</Example>

## Context colors

Checkboxes accept a `color` property to color the check indicator with any of the Chassis contextual colors.

<Example>
  <Checkbox color="secondary" id="checkSecondary" label="Secondary checkbox" defaultSelected />
</Example>

## Without labels

Remember to still provide some form of accessible name for assistive technologies (for instance, using `aria-label`).

<Example>
  <Checkbox id="checkboxNoLabel" value="" aria-label="..." />
</Example>

## Toggle buttons

Create button-like checkboxes by using the `button` property on `<Checkbox>`. These toggle buttons can further be grouped in a button group if needed.

<Example>
  <Checkbox
    button={{ color: 'primary' }}
    id="button-check"
    autoComplete="off"
    label="Single toggle"
  />
</Example>

<Example>
  <Checkbox
    button={{ color: 'primary' }}
    id="button-check-2"
    autoComplete="off"
    label="Checked"
    defaultSelected
  />
</Example>

<Example>
  <Checkbox
    button={{ color: 'primary' }}
    id="button-check-3"
    autoComplete="off"
    label="Disabled"
    disabled
  />
</Example>

### Outlined styles

Different variants of button, such at the various outlined styles, are supported.

<Example>
  <div>
    <Checkbox
      button={{ color: 'primary', variant: 'outline' }}
      id="button-check-outlined"
      autoComplete="off"
      label="Single toggle"
    />
  </div>
  <div>
    <Checkbox
      button={{ color: 'secondary', variant: 'outline' }}
      id="button-check-2-outlined"
      autoComplete="off"
      label="Checked"
      defaultSelected
    />
  </div>
</Example>

## Groups

`<CheckboxGroup>` manages a set of related checkboxes as a single array of selected values, with an optional shared description and validation feedback.

<Example>
  <CheckGroupExample client:load />
</Example>

### Orientation

Like `<RadioGroup>`, `<CheckboxGroup>` accepts an `orientation` property to lay its checkboxes out on the same horizontal row instead of stacking them.
