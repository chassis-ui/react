## Overview

`<Collapse>` shows and hides its children, driven by the `visible` prop — a button or link
elsewhere on the page typically toggles it. Collapsing an element animates its `height` from the
current value down to `0`. Because of how CSS handles that animation, `padding` can't be applied
directly to a `.collapse` element; wrap the content in its own element and pad that instead.
