## Overview

`Tabs` organizes content into sections, showing one at a time. Unlike hand-wiring a `Nav` to a set of manually-toggled panels, `Tabs` handles keyboard navigation (arrow keys, Home/End), roving tab focus, and the `role="tablist"`/`role="tab"`/`role="tabpanel"` + `aria-selected`/`aria-controls`/`aria-labelledby` wiring between them. Switching tabs also cross-fades their panels automatically.

Compose a `TabList` of `Tab`s, followed by one `TabPanel` per tab. A tab and its panel are paired by a matching `id` — not by position, and not by React's own `key` (each still needs its own `key`, as with any list). `Tabs`/`TabList`/`Tab`/`TabPanel` mirror the names of the react-aria hooks they're built on (`useTabList`, `useTab`, `useTabPanel`).

## Variants and sizes

Pass `variant="segments"` to `TabList` for a segmented control instead of the default tabs. The variant was called `pills` before `@chassis-ui/css` 0.6: `variant="pills"` still renders it, and is deprecated.

</Example>

Pass `variant="underline"` to mark the selected tab with a line under it, and `size="sm"` or `size="lg"` to scale the tabs of any variant.

Add `disabled` to a `Tab` to remove it from keyboard navigation and prevent it from being selected.

## Vertical

Pass `orientation="vertical"` to `Tabs` to stack the tabs. The list gets the `flex-column` class and `aria-orientation="vertical"`, and the up and down arrow keys move between the tabs. The panels stay below the list unless the root is laid out: here `className="d-flex align-items-start gap-md"` puts them beside it.

</Example>

## Overflow

Wrap the `TabList` in a [`NavOverflow`]([[docsref:/components/nav-overflow#tabs]]), inside the `Tabs`, to move the tabs that don't fit on one line into a "More" menu. Set `keepVisible` on a `Tab` that should never move.

## Controlled selection

Pass `selectedKey`/`onSelectionChange` to `Tabs` to control which tab is selected externally, e.g. to sync it with the URL. Omit them (use `defaultSelectedKey` instead) to let `Tabs` manage selection internally.
