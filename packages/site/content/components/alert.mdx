## Overview

`<Alert>` renders a `<dialog>` with `role="alertdialog"` and opens it as a modal dialog, the way
[`Modal`]([[docsref:/components/modal]]) does. Use it for a decision the flow can't continue
without: confirming a destructive action, acknowledging an error. For an overlay that doesn't
demand a decision, use `Modal`; for a message that doesn't interrupt, use `Notification`.

An alert waits for an explicit choice, so by default neither a click on the backdrop nor the
Escape key closes it; the alert bounces instead. Set `backdrop` and `keyboard` to allow them.

## Basic usage

Compose an `<AlertIcon>` (optional), an `<AlertBody>` with an `<AlertTitle>` and an `<AlertText>`,
and an `<AlertFooter>` with the actions. The footer lays the actions out right to left, so write
the primary action first. `<AlertCancel>` is the least destructive action: it closes the alert, and
it has focus when the alert opens.

## Accessibility

`<Alert>` names itself with its `<AlertTitle>` (`aria-labelledby`) and describes itself with its
`<AlertCode>` and `<AlertText>` (`aria-describedby`), the two an `alertdialog` needs. Each part is
listed under the id it has on the page (your own `id`, or the child's under `asChild`), in page
order, and only while it is rendered. So both attributes are added once the alert has mounted,
never in the server's HTML. Set your own `aria-labelledby` or `aria-describedby` to point
elsewhere.

When the alert opens, focus moves to its first element with `data-autofocus`: `<AlertCancel>` has
it, so the least destructive action is focused, as the
[WAI-ARIA pattern](https://www.w3.org/WAI/ARIA/apg/patterns/alertdialog/) recommends. Give an
earlier element `data-autofocus` to focus it instead, or opt `<AlertCancel>` out with
`data-autofocus="false"`. React's `autoFocus` isn't enough: in a page rendered in the browser,
React writes no `autofocus` attribute for the dialog to find.

When the alert closes, focus returns to the element that had it when the alert opened. After a
chain of alerts, that is the element that opened the first one.
