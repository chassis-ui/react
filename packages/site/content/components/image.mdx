import { Image } from '@chassis-ui/react'


## Responsive images

Images in Chassis are made responsive with `fluid` property. This applies `max-width: 100%;` and `height: auto;` to the image so that it scales with the parent element.

<Example>
  <Image fluid src="https://placehold.co/800x400" />
</Example>

## Image thumbnails

In addition to our border-radius utilities, you can use prop`thumbnail` to give an image a rounded 1px border appearance.

<Example>
  <Image rounded thumbnail src="https://placehold.co/800x400" width={200} height={200} />
</Example>

## Aligning images

Align images with the `align` property.

<Example>
  <div className="clearfix">
    <Image align="start" rounded src="https://placehold.co/800x400" width={200} height={200} />
    <Image align="end" rounded src="https://placehold.co/800x400" width={200} height={200} />
  </div>
</Example>

<Example>
  <div className="clearfix">
    <Image align="center" rounded src="https://placehold.co/800x400" width={200} height={200} />
  </div>
</Example>

<Example>
  <div className="text-center">
    <Image rounded src="https://placehold.co/800x400" width={200} height={200} />
  </div>
</Example>
