## Overview

`CxTextInput` is a styled, accessible replacement for a native single-line `<input>`. It's built on React Aria's `useTextField` hook, which wires `aria-describedby` / `aria-labelledby` to the ids generated for an associated label, help text, and validation feedback.

</Example>

## As a form field

Pass `label` / `help` / `invalid` / `invalidFeedback` / `valid` / `validFeedback` directly to `CxTextInput` to render it together with an associated `CxFormLabel`, `CxFormHelp`, and `CxFormFeedback`, already wired up — see [Form Field]([[docsref:/forms/form-field]]) instead when a control needs to be grouped with companion content under one label.

</Example>

## Types

`CxTextInput` accepts any single-line, text-valued native `type`: `text`, `password`, `email`, `tel`, `url`, `search`, `date`, `datetime-local`, `month`, `week`, and `time`. The value is passed straight through to the underlying `<input>`, so browser-native behaviors like password reveal toggles, email validation, and date pickers all work as expected.

<Example class="vstack gap-medium">
  <TypesExample client:load />
</Example>

Color and file inputs need bespoke rendering (a swatch, a themed file-selector button) that a plain text field can't provide, so they have their own dedicated components instead — see [File Input]([[docsref:/forms/file-input]]) and [Color Input]([[docsref:/forms/color-input]]). For a richer date-picking experience with a calendar popup, see [Date Picker]([[docsref:/forms/datepicker]]).

## Disabled

Add the `disabled` boolean attribute to give the control a muted color. Browsers also remove disabled controls from the tab order and from form submission automatically.

<Example class="vstack gap-medium">
  <DisabledExample client:load />
</Example>

## Readonly

Add the `readOnly` boolean attribute to prevent the value from being edited. Unlike `disabled`, a read-only control stays focusable and is still included in form submission — only typing into it is blocked — and it keeps the same appearance as an editable control.

<Example class="vstack gap-medium">
  <ReadonlyExample client:load />
</Example>

## Plain text

Pair the `plainText` prop with `readOnly` to render the value as plain text instead of an editable-looking field — useful for read-only values that should still line up with the editable fields around them.

<Example class="vstack gap-medium">
  <PlainTextExample client:load />
</Example>

## Controlled value

Pass `value` and `onChange` to control the value from external state. `onChange` receives the new string value directly rather than a change event, so it can be passed straight to a state setter. Omit them (optionally passing `defaultValue` instead) to let the component manage its own value.
