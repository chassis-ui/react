import { Progress, Button } from '@chassis-ui/react'

## Example

Progress components are built with two HTML elements, some CSS to set the width, and a few attributes. We don't use [the HTML5 `<progress>` element](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/progress), ensuring you can stack progress bars, animate them, and place text labels over them.

## Basic usage

<Example>
  <Progress className="mb-medium">
    <Progress.Bar value={0} />
  </Progress>
  <Progress className="mb-medium">
    <Progress.Bar value={25} />
  </Progress>
  <Progress className="mb-medium">
    <Progress.Bar value={50} />
  </Progress>
  <Progress className="mb-medium">
    <Progress.Bar value={75} />
  </Progress>
  <Progress className="mb-medium">
    <Progress.Bar value={100} />
  </Progress>
</Example>

## Labels

Add labels to your progress bars by placing text within the `<Progress.Bar>`.

<Example>
  <Progress className="mb-medium">
    <Progress.Bar value={25}>25%</Progress.Bar>
  </Progress>
</Example>

## Height

We only set a `height` value on the `<Progress>`, so if you change that value the inner `<Progress.Bar>` will automatically resize accordingly.

<Example>
  <Progress height={1} className="mb-medium">
    <Progress.Bar value={25}></Progress.Bar>
  </Progress>
  <Progress height={20} className="mb-medium">
    <Progress.Bar value={25}></Progress.Bar>
  </Progress>
</Example>

## Backgrounds

Use `color` prop to change the appearance of individual progress bars.

<Example>
  <Progress className="mb-medium">
    <Progress.Bar color="success" value={25} />
  </Progress>
  <Progress className="mb-medium">
    <Progress.Bar color="info" value={50} />
  </Progress>
  <Progress className="mb-medium">
    <Progress.Bar color="warning" value={75} />
  </Progress>
  <Progress className="mb-medium">
    <Progress.Bar color="danger" value={100} />
  </Progress>
</Example>

## Multiple bars

Include multiple progress bars in a progress component if you need.

<Example>
  <Progress className="mb-medium">
    <Progress.Bar value={15} />
    <Progress.Bar color="success" value={30} />
    <Progress.Bar color="info" value={20} />
  </Progress>
</Example>

## Striped

Add `variant="striped"` to any `<Progress.Bar>` to apply a stripe via CSS gradient over the progress bar's background context.

<Example>
  <Progress className="mb-medium">
    <Progress.Bar color="success" variant="striped" value={25} />
  </Progress>
  <Progress className="mb-medium">
    <Progress.Bar color="info" variant="striped" value={50} />
  </Progress>
  <Progress className="mb-medium">
    <Progress.Bar color="warning" variant="striped" value={75} />
  </Progress>
  <Progress className="mb-medium">
    <Progress.Bar color="danger" variant="striped" value={100} />
  </Progress>
</Example>

## Animated stripes

The striped gradient can also be animated. Add `animated` property to `<Progress.Bar>` to animate the stripes right to left via CSS3 animations.

<Example>
  <Progress className="mb-medium">
    <Progress.Bar color="success" variant="striped" animated value={25} />
  </Progress>
  <Progress className="mb-medium">
    <Progress.Bar color="info" variant="striped" animated value={50} />
  </Progress>
  <Progress className="mb-medium">
    <Progress.Bar color="warning" variant="striped" animated value={75} />
  </Progress>
  <Progress className="mb-medium">
    <Progress.Bar color="danger" variant="striped" animated value={100} />
  </Progress>
</Example>
