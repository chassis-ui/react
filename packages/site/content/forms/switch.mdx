import { CxSwitch } from '@chassis-ui/react'

## Approach

A switch has the markup of a custom checkbox but renders as a toggle switch via `<CxSwitch>`. Switches also support the `disabled` attribute.

<Example>
  <CxSwitch label="Default switch checkbox input" id="formSwitchCheckDefault" />
  <CxSwitch label="Checked switch checkbox input" id="formSwitchCheckChecked" defaultSelected />
  <CxSwitch label="Disabled switch checkbox input" id="formSwitchCheckDisabled" disabled />
  <CxSwitch
    label="Disabled checked switch checkbox input"
    id="formSwitchCheckCheckedDisabled"
    defaultSelected
    disabled
  />
</Example>

## Sizes

Apply the `size` property (`small` or `large`) to change the size of a switch.

<Example>
  <CxSwitch size="small" label="Small switch checkbox input" id="formSwitchCheckDefaultSm" />
  <CxSwitch label="Default switch checkbox input" id="formSwitchCheckDefault" />
  <CxSwitch size="large" label="Large switch checkbox input" id="formSwitchCheckDefaultLg" />
</Example>

## Context colors

Switches accept a `color` property to color the switch indicator with any of the Chassis contextual colors.

<Example>
  <CxSwitch color="danger" id="switchDanger" label="Danger switch" defaultSelected />
</Example>
