import { useState } from 'react'
import { Button, Card, Placeholder } from '@chassis-ui/react'


## About

Placeholders can be used to enhance the experience of your application. They're built only with HTML and CSS, meaning you don't need any JavaScript to create them. You will, however, need some custom JavaScript to toggle their visibility. Their appearance, context, and sizing can be easily customized with our utility classes.


## Example

In the example below, we take a typical card component and recreate it with placeholders applied to create a "loading card". Size and proportions are the same between the two.

<Example className="d-flex justify-content-around">
  <Card style={{ width: '18rem' }}>
    <Card.Image orientation="top" src="https://placehold.co/800x400" />
    <Card.Body>
      <Card.Title>Card title</Card.Title>
      <Card.Text>
        Some quick example text to build on the card title and make up the bulk of the card's
        content.
      </Card.Text>
      <Button href="#">Go somewhere</Button>
    </Card.Body>
  </Card>
  <Card style={{ width: '18rem' }}>
    <Card.Image component="svg" orientation="top" width="100%" height="162" xmlns="http://www.w3.org/2000/svg" role="img" aria-label="Placeholder" preserveAspectRatio="xMidYMid slice" focusable="false">
      <title>Placeholder</title><rect width="100%" height="100%" fill="#868e96"></rect>
    </Card.Image>  
    <Card.Body>
      <Placeholder component={Card.Title} animation="glow" xs={7}>
        <Placeholder xs={6} />
      </Placeholder>
      <Placeholder component={Card.Text} animation="glow">
        <Placeholder xs={7} />
        <Placeholder xs={4} />
        <Placeholder xs={4} />
        <Placeholder xs={6} />
        <Placeholder xs={8} />
      </Placeholder>
      <Placeholder component={Button} disabled href="#" tabIndex={-1} xs={6}></Placeholder>
    </Card.Body>
  </Card>
</Example>

## How it works

Create placeholders with the `<Placeholder>` component and a grid column propx (e.g., `xs={6}`) to set the `width`. They can replace the text inside an element or be added as a modifier class to an existing component.

We apply additional styling to `Button`s via `::before` to ensure the `height` is respected. You may extend this pattern for other situations as needed, or add a `&nbsp;` within the element to reflect the height when actual text is rendered in its place.

<Example>
  <p aria-hidden="true">
    <Placeholder xs={6} />
  </p>
  <Placeholder component={Button} aria-hidden="true" disabled href="#" tabIndex={-1} xs={4}></Placeholder>
</Example>

<Callout className="mb-4" context="info">
  The use of <code>aria-hidden="true"</code> only indicates that the element should be hidden to screen readers. The <strong>loading</strong> behavior of the placeholder depends on how authors will actually use the placeholder styles, how they plan to update things, etc. Some JavaScript code may be needed to *swap* the state of the placeholder and inform AT users of the update.
</Callout>

### Width

You can change the `width` through grid column classes, width utilities, or inline styles.

<Example>
  <Placeholder xs={6} />
  <Placeholder className="w-75" />
  <Placeholder style={{ width: '30%'}} />
</Example>

### Color

By default, the `<Placeholder>` uses `currentColor`. This can be overridden with a custom context or utility class.

<Example>
  <Placeholder xs={12} />

  <Placeholder color="primary" xs={12} />
  <Placeholder color="secondary" xs={12} />
  <Placeholder color="success" xs={12} />
  <Placeholder color="danger" xs={12} />
  <Placeholder color="warning" xs={12} />
  <Placeholder color="info" xs={12} />
  <Placeholder color="light" xs={12} />
  <Placeholder color="dark" xs={12} />
</Example>

### Sizing

The size of `<Placeholder>`s are based on the typographic style of the parent element. Customize them with `size` prop: `lg`, `sm`, or `xs`.

<Example>
  <Placeholder xs={12} size="large"/>
  <Placeholder xs={12}/>
  <Placeholder xs={12} size="small"/>
  <Placeholder xs={12} size="xsmall"/>
</Example>

### Animation

Animate placeholders with `animation="glow"` or `animation="wave"` to better convey the perception of something being _actively_ loaded.

<Example>
  <Placeholder component="p" animation="glow">
    <Placeholder xs={12} />
  </Placeholder>  
  <Placeholder component="p" animation="wave">
    <Placeholder xs={12} />
  </Placeholder> 
</Example>
