## Overview

`<Radio>` replaces the browser's default radio input, for selecting one option from many. It renders the modern, wrapper-based `.check-input` markup nested inside a single `<label>` — passing `label` renders an accessible, fully-clickable control with no extra markup required.

`<Radio>` is built on [React Aria](https://react-spectrum.adobe.com/react-aria/) for full keyboard and screen-reader support. Radios have no meaningful standalone state — a radio only makes sense as part of a mutually-exclusive set — so `<Radio>` must always be rendered inside a `<RadioGroup>`, which manages selection and arrow-key navigation between options.

## Radios

Radios are always rendered inside a `<RadioGroup>`, which owns selection and gives the group a `<fieldset>`/`<legend>` so assistive technology announces the group's purpose alongside each option.
