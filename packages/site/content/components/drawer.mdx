## Behaviors

### Body scroll

By default, body scroll is locked while a drawer is open. Set `scroll` to allow the page to scroll while the drawer is open. Combine with `backdrop={false}` to remove the backdrop entirely.

<Example>
  <BodyScrollExample client:load />
</Example>

### Static backdrop

Set `backdrop="static"` to prevent closing on backdrop click — the drawer nudges briefly to signal it requires explicit action. Add `keyboard={false}` to also disable Escape.

<Example>
  <StaticBackdropExample client:load />
</Example>

### Animation

Drawers animate in and out by default. Add `instant` to skip all transitions.

## Appearance

`sheet` removes the inset gap, border radius, and border — the panel sits flush against the viewport edge. `translucent` applies a frosted-glass background. Both combine freely with placement and behavior props.

## Footer layout

`<DrawerFooter>` uses `flex-direction: row-reverse`, so buttons are right-aligned without extra props — write the **primary action first** in source, it renders on the right. At the small breakpoint, buttons stretch to equal widths. Add `stacked` to stack them as full-width columns instead.

## Responsive

Set `responsive` to a breakpoint (`'small' | 'medium' | 'large' | 'xlarge' | '2xlarge'`) to render as a drawer only below that breakpoint — above it, the panel renders inline as a flex container instead (`.drawer-header` hidden, `.drawer-body` laid out as a row). This is the basis for navigation that collapses off-screen on narrow viewports and expands inline on wide ones, as used by [Navbar]([[docsref:/components/navbar]])'s collapsible menu region.

## Accessibility

The `<dialog>` element carries an implicit `role="dialog"` when opened with `showModal()`. `<Drawer>` generates an id and wires it to `aria-labelledby` automatically — render a `<DrawerTitle>` anywhere inside and it picks up that id, giving the drawer an accessible name with no manual wiring. Pass an explicit `id` to `<DrawerTitle>` to opt out, or set your own `aria-labelledby` on `<Drawer>` to point elsewhere.

Focus moves to the drawer on open — to a specific element if it has `autofocus`, otherwise to the drawer itself. After the drawer closes, focus returns to whichever element was focused when it opened. Opening a second drawer while one is already open automatically closes the first.
