import { CxCol, CxContainer, CxRow } from '@chassis-ui/react'

## How they work

- **Gutters are the gaps between column content, created by horizontal `padding`.** We set `padding-right` and `padding-left` on each column, and use negative `margin` to offset that at the start and end of each row to align content.

- **Gutters start at `1.5rem` (`24px`) wide.** This allows us to match our grid to the padding and margin spacers scale.

- **Gutters can be responsively adjusted.** Use breakpoint-specific gutter props to modify horizontal gutters, vertical gutters, and all gutters.

## Horizontal gutters

`{breakpoint}={{ gutterX: * }}` props can be used to control the horizontal gutter widths. The `<CxContainer>` or `<CxContainer fluid>` parent may need to be adjusted if larger gutters are used too to avoid unwanted overflow, using a matching padding utility. For example, in the following example we've increased the padding with `.px-4`:

<Example>
  <CxContainer className="px-4">
    <CxRow xs={{ gutterX: 5 }}>
      <CxCol>
        <div className="p-3 border bg-light">Custom column padding</div>
      </CxCol>
      <CxCol>
        <div className="p-3 border bg-light">Custom column padding</div>
      </CxCol>
    </CxRow>
  </CxContainer>
</Example>

An alternative solution is to add a wrapper around the `<CxRow>` with the `.overflow-hidden` class:

<Example>
  <CxContainer className="overflow-hidden">
    <CxRow xs={{ gutterX: 5 }}>
      <CxCol>
        <div className="p-3 border bg-light">Custom column padding</div>
      </CxCol>
      <CxCol>
        <div className="p-3 border bg-light">Custom column padding</div>
      </CxCol>
    </CxRow>
  </CxContainer>
</Example>

## Vertical gutters

`{breakpoint}={{ gutterY: * }}` props can be used to control the vertical gutter widths. Like the horizontal gutters, the vertical gutters can cause some overflow below the `<CxRow>` at the end of a page. If this occurs, you add a wrapper around `<CxRow>` with the `.overflow-hidden` class:

<Example>
  <CxContainer className="overflow-hidden">
    <CxRow xs={{ gutterY: 5 }}>
      <CxCol xs={{ span: 6 }}>
        <div className="p-3 border bg-light">Custom column padding</div>
      </CxCol>
      <CxCol xs={{ span: 6 }}>
        <div className="p-3 border bg-light">Custom column padding</div>
      </CxCol>
      <CxCol xs={{ span: 6 }}>
        <div className="p-3 border bg-light">Custom column padding</div>
      </CxCol>
      <CxCol xs={{ span: 6 }}>
        <div className="p-3 border bg-light">Custom column padding</div>
      </CxCol>
    </CxRow>
  </CxContainer>
</Example>

## Horizontal & vertical gutters

`{breakpoint}={{ gutter: * }}` props can be used to control the horizontal gutter widths, for the following example we use a smaller gutter width, so there won't be a need to add the `.overflow-hidden` wrapper class.

## No gutters

The gutters between columns in our predefined grid props can be removed with `{breakpoint}={{ gutter: 0 }}`. This removes the negative `margin`s from `<CxRow>` and the horizontal `padding` from all immediate children columns.

**Need an edge-to-edge design?** Drop the parent `<CxContainer>` or `<CxContainer fluid>`.

In practice, here's how it looks. Note you can continue to use this with all other predefined grid props (including column widths, responsive tiers, reorders, and more).

<Example>
  <div className="docs-example-row">
    <CxRow xs={{ gutter: 0 }}>
      <CxCol sm={6} md={8}>.small:col-6 .medium:col-8</CxCol>
      <CxCol xs={6} md={4}>.col-6 .medium:col-4</CxCol>
    </CxRow>
  </div>
</Example>
