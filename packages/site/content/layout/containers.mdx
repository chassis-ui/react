## How they work

Containers are the most basic layout element in Bootstrap React and are **required when using our default grid system**. Containers are used to contain, pad, and (sometimes) center the content within them. While containers *can* be nested, most layouts do not require a nested container.

Bootstrap React comes with three different containers:

- `<CxContainer>`, which sets a `max-width` at each responsive breakpoint
- `<CxContainer fluid>`, which is `width: 100%` at all breakpoints
- `<CxContainer {sm|md|lg|xl|xxl}>`, which is `width: 100%` until the specified breakpoint

## Default container

Our default `<CxContainer>` class is a responsive, fixed-width container, meaning its `max-width` changes at each breakpoint.

<Example>
  <CxContainer>
    Content here
  </CxContainer>
</Example>

```jsx
<CxContainer>
  Content here
</CxContainer>
```

## Responsive containers

Responsive containers allow you to specify a class that is 100% wide until the specified breakpoint is reached, after which we apply `max-width`s for each of the higher breakpoints. For example, `<CxContainer sm>` is 100% wide to start until the `sm` breakpoint is reached, where it will scale up with `md`, `lg`, `xl`, and `xxl`.

<Example>
  <CxContainer sm>100% wide until small breakpoint</CxContainer>
  <CxContainer md>100% wide until medium breakpoint</CxContainer>
  <CxContainer lg>100% wide until large breakpoint</CxContainer>
  <CxContainer xl>100% wide until extra large breakpoint</CxContainer>
  <CxContainer xxl>100% wide until extra extra large breakpoint</CxContainer>
</Example>

```jsx
<CxContainer sm>100% wide until small breakpoint</CxContainer>
<CxContainer md>100% wide until medium breakpoint</CxContainer>
<CxContainer lg>100% wide until large breakpoint</CxContainer>
<CxContainer xl>100% wide until extra large breakpoint</CxContainer>
<CxContainer xxl>100% wide until extra extra large breakpoint</CxContainer>
```

## Fluid containers

Use `<CxContainer fluid>` for a full width container, spanning the entire width of the viewport.

<Example>
  <CxContainer fluid>
    Content here
  </CxContainer>
</Example>

```jsx
<CxContainer fluid>
  Content here
</CxContainer>
```
