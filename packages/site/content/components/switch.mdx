## Overview

A switch has the markup of a custom checkbox but renders as a toggle switch via `<Switch>`. It
supports the native `disabled` attribute, same as any checkbox input.

<Example>
  <BasicExample client:load />
</Example>

## Sizes

Set `size` to `"small"` or `"large"` to change a switch's dimensions; the default renders at
medium size.

<Example>
  <SizeExample client:load />
</Example>

## Context colors

Set `color` to any of the Chassis context colors to tint the switch indicator when selected.
