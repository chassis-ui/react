## Overview

`<Progress>` renders both the wrapper and the inner bar from a single `value` prop, using its own markup instead of [the HTML5 `<progress>` element](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/progress) for full control over color, stripes, animation, and text labels.

## Basic usage

Pass `label` and `showValue` alongside `value` to render a caption and the current percentage above the bar.
