import { CxBadge, CxButton } from '@chassis-ui/react'

## About

Badges are lightweight components used to add counts, labels, or status indicators to content. They highlight new items, display notification counts, and provide supplementary information. Badges work with any content or component and are available in multiple styles and colors.

## Basic usage

A `<CxBadge>` scales to suit the size of the parent element by using relative font sizing and `em` units.

<Example>
  <h1>Example heading <CxBadge context="secondary">New</CxBadge></h1>
  <h2>Example heading <CxBadge context="secondary">New</CxBadge></h2>
  <h3>Example heading <CxBadge context="secondary">New</CxBadge></h3>
  <h4>Example heading <CxBadge context="secondary">New</CxBadge></h4>
  <h5>Example heading <CxBadge context="secondary">New</CxBadge></h5>
  <h6>Example heading <CxBadge context="secondary">New</CxBadge></h6>
</Example>

Badges can be used as part of links or buttons to provide a counter.

<Example>
  <CxButton context="primary">
    Notifications <CxBadge context="secondary">4</CxBadge>
  </CxButton>
</Example>

<Callout context="info">
  <p>
    Badge content can be confusing for screen reader users without proper context. Use semantic roles by adding <code>role="status"</code> for counters or <code>role="presentation"</code> for decorative badges, and provide descriptions with <code>aria-label</code> to explain the badge's meaning.
  </p>
</Callout>

<Example>
  <CxButton context="primary">
    Profile <CxBadge context="secondary" role="status" aria-label="unread messages">9</CxBadge>
  </CxButton>
</Example>

## Color variants

Set the `context` prop to one of the Chassis themed colors to apply the appropriate background and text colors.

<Example>
  <CxBadge context="default">Default</CxBadge>
  <CxBadge context="alternate">Alternate</CxBadge>
  <CxBadge context="primary">Primary</CxBadge>
  <CxBadge context="secondary">Secondary</CxBadge>
  <CxBadge context="neutral">Neutral</CxBadge>
  <CxBadge context="danger">Danger</CxBadge>
  <CxBadge context="success">Success</CxBadge>
  <CxBadge context="warning">Warning</CxBadge>
  <CxBadge context="info">Info</CxBadge>
  <CxBadge context="black">Black</CxBadge>
  <CxBadge context="white">White</CxBadge>
</Example>

<Callout context="info">
  <p>
    Color alone shouldn't convey meaning as it's not perceived by assistive technology users. Ensure clarity through text with adequate contrast, ARIA attributes where needed, and consider using the <code>.visually-hidden</code> class for screen reader content.
  </p>
</Callout>

### Outline style

Set `variant="outline"` to create badges with a transparent background, colored border and text.

<Example>
  <CxBadge context="default" variant="outline">Default</CxBadge>
  <CxBadge context="primary" variant="outline">Primary</CxBadge>
  <CxBadge context="secondary" variant="outline">Secondary</CxBadge>
  <CxBadge context="danger" variant="outline">Danger</CxBadge>
  <CxBadge context="success" variant="outline">Success</CxBadge>
  <CxBadge context="warning" variant="outline">Warning</CxBadge>
  <CxBadge context="info" variant="outline">Info</CxBadge>
</Example>

### Smooth style

Set `variant="smooth"` to create badges with a subdued background color and matching text color, for a softer, more subtle appearance.

<Example>
  <CxBadge context="default" variant="smooth">Default</CxBadge>
  <CxBadge context="primary" variant="smooth">Primary</CxBadge>
  <CxBadge context="secondary" variant="smooth">Secondary</CxBadge>
  <CxBadge context="danger" variant="smooth">Danger</CxBadge>
  <CxBadge context="success" variant="smooth">Success</CxBadge>
  <CxBadge context="warning" variant="smooth">Warning</CxBadge>
  <CxBadge context="info" variant="smooth">Info</CxBadge>
</Example>

## Size variants

Set `size="small"` or `size="large"` to adjust the size of the badge for compact spaces or greater emphasis. Combine with `circle` for round counters.

<Example>
  <CxBadge context="primary" size="small">Small</CxBadge>
  <CxBadge context="primary">Medium</CxBadge>
  <CxBadge context="primary" size="large">Large</CxBadge>
  <CxBadge context="primary" size="small" circle>2</CxBadge>
  <CxBadge context="primary" circle>2</CxBadge>
  <CxBadge context="primary" size="large" circle>2</CxBadge>
</Example>

## Use cases

### With components

Badges work well inside buttons and other components to indicate counts, status, or other supplementary information.

<Example>
  <CxButton context="primary">
    Notifications <CxBadge context="secondary" circle role="status" aria-label="new notifications">2</CxBadge>
  </CxButton>
</Example>

### Positioned badges

Set the `position` prop to place a badge in one of the corners of a link or button. The parent needs `position-relative` (or another positioning context) for this to work.

<Example>
  <CxButton context="primary" className="position-relative">
    Profile
    <CxBadge context="danger" position="top-start" circle>
      99+ <span className="visually-hidden">unread messages</span>
    </CxBadge>
  </CxButton>
  <CxButton context="primary" className="position-relative ms-xsmall">
    Profile
    <CxBadge context="danger" position="top-end" circle>
      99+ <span className="visually-hidden">unread messages</span>
    </CxBadge>
  </CxButton>
  <br/>
  <CxButton context="primary" className="position-relative">
    Profile
    <CxBadge context="danger" position="bottom-start" circle>
      99+ <span className="visually-hidden">unread messages</span>
    </CxBadge>
  </CxButton>
  <CxButton context="primary" className="position-relative ms-xsmall">
    Profile
    <CxBadge context="danger" position="bottom-end" circle>
      99+ <span className="visually-hidden">unread messages</span>
    </CxBadge>
  </CxButton>
</Example>

### Custom corners

Beyond the default rounded appearance and the `circle` prop, apply border-radius utility classes through `className` for precise control over corners.

<Example>
  <CxBadge context="primary" className="rounded-zero">Sharp</CxBadge>
  <CxBadge context="primary" className="rounded-small">Blunt</CxBadge>
  <CxBadge context="primary" className="rounded-medium">Soft</CxBadge>
  <CxBadge context="primary" className="rounded-full">Pill</CxBadge>
</Example>
