## Overview

`useDrawer()` reads a close handler from React context, provided by the nearest enclosing
[`<Drawer>`]([[docsref:/components/drawer]]). Call it from any component rendered inside that
`<Drawer>` — a plain `Button` in a `DrawerFooter`, custom body content — instead of threading a
close callback down through props from wherever `visible`/`onClose` are managed.

Outside a `<Drawer>`, `useDrawer()` returns a no-op `close` rather than throwing, so a component
that calls it doesn't have to guard against rendering outside one.

## API

### useDrawer

```ts
function useDrawer(): { close: () => void }
```

`useDrawer` takes no arguments. Its return value is a single `close` function that requests the
enclosing `<Drawer>` close, running the same close transition and `onClose` callback as dismissing
it via the backdrop, the Escape key, or a built-in close control would.
