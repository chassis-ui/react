import { CxSpinner, CxButton } from '@chassis-ui/react'

## About

Chassis "spinners" can be used to show the loading state in your projects. They're built only with HTML and CSS, meaning you don't need any JavaScript to create them. You will, however, need some custom JavaScript to toggle their visibility. Their appearance, alignment, and sizing can be easily customized with our amazing utility classes.

For accessibility purposes, each loader here includes `role="status"` and a nested `<span className="visually-hidden">Loading...</span>`.

## Border spinner

Use the border spinners for a lightweight loading indicator.

## Basic usage

<Example>
  <CxSpinner/>
</Example>

### Colors

The border spinner uses `currentColor` for its `border-context`. You can use any of our text context utilities on the standard spinner.

<Example>
  <CxSpinner context="primary"/>
  <CxSpinner context="secondary"/>
  <CxSpinner context="success"/>
  <CxSpinner context="danger"/>
  <CxSpinner context="warning"/>
  <CxSpinner context="info"/>
  <CxSpinner context="light"/>
  <CxSpinner context="dark"/>
</Example>

## Growing spinner

If you don't fancy a border spinner, switch to the grow spinner. While it doesn't technically spin, it does repeatedly grow!

<Example>
  <CxSpinner variant="grow"/>
</Example>

Once again, this spinner is built with `currentColor`, so you can easily change its appearance. Here it is in blue, along with the supported variants.

<Example>
  <CxSpinner context="primary" variant="grow"/>
  <CxSpinner context="secondary" variant="grow"/>
  <CxSpinner context="success" variant="grow"/>
  <CxSpinner context="danger" variant="grow"/>
  <CxSpinner context="warning" variant="grow"/>
  <CxSpinner context="info" variant="grow"/>
  <CxSpinner context="light" variant="grow"/>
  <CxSpinner context="dark" variant="grow"/>
</Example>

## Size

Add `size="small"`property` to make a smaller spinner that can quickly be used within other components.

<Example>
  <CxSpinner size="small"/>
  <CxSpinner size="small" variant="grow"/>
</Example>

## Buttons

Use spinners within buttons to indicate an action is currently processing or taking place. You may also swap the text out of the spinner element and utilize button text as needed.

<Example>
  <CxButton disabled>
    <CxSpinner component="span" size="small" aria-hidden="true"/>
  </CxButton>
  <CxButton disabled>
    <CxSpinner component="span" size="small" aria-hidden="true"/>
    Loading...
  </CxButton>
</Example>

<Example>
  <CxButton disabled>
    <CxSpinner component="span" size="small" variant="grow" aria-hidden="true"/>
  </CxButton>
  <CxButton disabled>
    <CxSpinner component="span" size="small" variant="grow" aria-hidden="true"/>
    Loading...
  </CxButton>
</Example>
