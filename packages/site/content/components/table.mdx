## Overview

`Table` is a real ARIA grid (`role="grid"`) — arrow keys move focus between cells, columns can be sortable, and rows can be selectable, all handled by React Aria's table hooks. Composing it uses `TableHeader`/`TableColumn`/`TableBody`/`TableRow`/`TableCell` as data — read to build the table's collection — rather than plain `<thead>`/`<tbody>` JSX. `Table` renders the real `<table>` markup itself from that collection.

This is a deliberate trade: the authoring model is less "just markup" than most of the rest of Chassis React, in exchange for real sorting, selection, and keyboard grid navigation that would otherwise need to be hand-rolled.

## Sorting

Add `allowsSorting` to a `TableColumn` to make it clickable (and keyboard-activatable). `Table` doesn't sort the data itself — it reports the requested column/direction via `onSortChange`, so pair it with `sortDescriptor` and sort the array in that handler, as shown below.

## Selection

Set `selectionMode="multiple"` for checkbox-based row selection (including a select-all checkbox in the header), or `selectionMode="single"` to select a row by clicking anywhere in it. Control the selection with `selectedKeys`/`onSelectionChange` — a selected row gets the same `.active` highlight the table's `active` variant applies.

## Keyboard navigation

Once a cell has focus, arrow keys move focus across the grid — no extra setup required. Typeahead, Home/End, and Page Up/Down navigation come from the same hooks.

## Variants

`bordered`, `borderless`, `hover`, `small`, `striped`, and `color` all apply to the `<table>` element itself, the same as any other table markup.

## Caption and footer

Pass `caption` for a `<caption>` above the table. Pass `footer` for a `<tfoot>` below it — footer content is rendered as plain markup, not part of the keyboard-navigable grid, since totals/summary rows don't need to participate in cell-by-cell navigation.

## Stacked tables

For tables with too many columns to read comfortably even with horizontal scrolling, set `stacked` to convert rows into stacked label/value blocks below a container width — `true` always stacks, or pass a breakpoint name to stack only below it. Resize the panel below to see it switch.

Each `TableColumn`'s text becomes the label shown before that column's value; set `textValue` on a column explicitly when its header isn't plain text (an icon, a `Tooltip`, etc.).

## Scope

- **No virtualization.** Every row renders directly — there's no windowing for very large datasets. React Aria doesn't ship a public general-purpose virtualizer for Table (its internal one isn't meant for outside use), and layering in a separate library (e.g. `@tanstack/react-virtual`) is a substantial enough change — fixed/measured row heights, a scroll container, and interaction with React Aria's own keyboard navigation and focus management — that it's deferred rather than bundled into this first pass. Most large datasets are better served by server-side pagination anyway.
- **No column resizing or reordering, no nested/expandable rows.** React Aria's table hooks support these, but they're not wired up here.
