For the `<Form>` element's own default behaviors and the `label`/`help`/validation props shared
across every form component, see [Working with Forms]([[docsref:/getting-started/working-with-forms]]).
This page covers structuring a form's layout with the grid system once those pieces are in place.

## Utilities

Margin utilities add basic structure to a form — grouping labels, controls, optional help text,
and validation messaging. Stick to `margin-bottom` utilities in a single direction throughout a
form for consistent spacing.

## Form grid

Build more complex forms with [`<Grid>`]([[docsref:/components/grid]]) for layouts that need
multiple columns, varied widths, or additional alignment options. `columns` gives a row of equal
fields.

<Example>
  <FormGridExample client:load />
</Example>

## Gaps

Set `gap` to a token of the spacing scale to change the space between fields. Without it, a grid
has the gutter of the breakpoint. The `.column-gap-{token}` and `.row-gap-{token}` utilities set
the inline and block directions independently.

<Example>
  <GuttersExample client:load />
</Example>

The grid also composes into more complex layouts, like a full address form. A `<Grid>` renders
the `<Form>` itself with `component={Form}`, and each field is a `<GridItem>` that fills the row
with `span="full"` and narrows from a breakpoint up.

<Example>
  <ComplexGridExample client:load />
</Example>

## Horizontal form

Create horizontal forms with a `<Grid>` per form group: the label takes the `.col-span-*`
classes and the control sits in a `<GridItem>`, both with `span="full"` below the breakpoint so
that they stack. Add `.col-form-label` to a `<FormLabel>` as well, so it's vertically centered with
its associated form control. `.row-gap-zero` keeps a stacked label close to its control, and a
control with no label starts at the control column with `start`.

<Example>
  <HorizontalFormExample client:load />
</Example>

### Label sizing

Add `.col-form-label-sm` or `.col-form-label-lg` on a `<FormLabel>` or `<legend>` to match
the size of a `.sm` or `.lg` control.

<Example>
  <LabelSizingExample client:load />
</Example>

## Column sizing

Give each field a `span` of the twelve columns to size it against the others — like
`<GridItem span="full" responsive={{ sm: { span: 6 } }}>` for a field that takes half the row from
the `sm` breakpoint.

<Example>
  <ColumnSizingExample client:load />
</Example>

## Auto-sizing

A grid sizes its columns from the container, so fields as wide as their content go in a
[`<Flex>`]([[docsref:/components/flex]]) instead: `wrap` lets them move to the next line, `align`
centers them vertically, and each takes only the space its content needs.

<Example>
  <AutoSizingExample client:load />
</Example>

Combine content-width fields with sized ones through the [fraction width utilities](https://chassis-ui.com/css/docs/utilities/sizing#fractions): `.w-100 sm:w-3/12` is a full-width field that takes a quarter of the row from `sm`. The fields that don't fit beside them wrap to the next line.

<Example>
  <AutoSizingSizedExample client:load />
</Example>

## Inline forms

Use a `<Flex>` that is a column below a breakpoint and a row from it. `gap` adds the spacing in
both directions, and `align: 'center'` vertically centers the form elements so the `<Checkbox>`
aligns properly.
