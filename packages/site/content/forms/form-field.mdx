import {
  CxChipInput,
  CxCombobox,
  CxComboboxItem,
  CxFormField,
  CxPasswordStrength,
  CxTextInput
} from '@chassis-ui/react'

## Approach

`<CxFormField>` wraps a form control (or a small group of them) with a `.form-field` grid layout, along with an associated `CxFormLabel`, `CxFormHelp`, and `CxFormFeedback` — see [chassis-css's Form Field docs](https://chassis-ui.com/css/docs/forms/form-field) for the underlying CSS.

`CxTextInput`, `CxSelect`, `CxTextarea`, and `CxRangeInput` already accept `label`/`help`/`invalidFeedback`/`validFeedback` props directly and wrap themselves — reach for those first. Use `<CxFormField>` when the control doesn't have its own field props yet (`CxCombobox`, `CxDatePicker`, `CxChipInput`, `CxOtpInput`), or when you need to group more than one element — like an input alongside a `CxPasswordStrength` meter — under a single label and help text.

Renders nothing but its `children` bare when none of `label`/`help`/`validFeedback`/`invalidFeedback` are set, so it's always safe to reach for.

## Examples

### Using a leaf's own field props

<Example>
  <CxTextInput
    label="Email address"
    help="We'll never share your email with anyone else."
    id="ffEmail"
  />
</Example>

### Wrapping a control with no field props of its own

<Example>
  <CxFormField label="Country" help="The billing region." ids={{ input: 'ffCountry' }}>
    <CxCombobox id="ffCountry" name="country" placeholder="Pick a country…">
      <CxComboboxItem id="us">United States</CxComboboxItem>
      <CxComboboxItem id="uk">United Kingdom</CxComboboxItem>
      <CxComboboxItem id="ca">Canada</CxComboboxItem>
    </CxCombobox>
  </CxFormField>
</Example>

### Grouping a control with companion content

<Example>
  <CxFormField label="Password" ids={{ input: 'ffPassword' }}>
    <CxTextInput autoComplete="new-password" id="ffPassword" type="password" />
    <CxPasswordStrength value="" />
  </CxFormField>
</Example>

### Validation feedback

`invalidFeedback`/`validFeedback` render only alongside a truthy `invalid`/`valid`, matching the leaf components' own validation props.

<Example>
  <CxFormField
    label="Username"
    invalid
    invalidFeedback="This username is already taken."
    ids={{ input: 'ffUsername' }}
  >
    <CxChipInput id="ffUsername" name="username" />
  </CxFormField>
</Example>

## Manual id wiring

`<CxFormField>` doesn't clone its children, so it can't wire ids onto a control it doesn't own. Pass matching values through the `ids` prop — `input` for `htmlFor` (or `label` for a group with no single input to target, wired via the control's own `aria-labelledby`) — and set `aria-describedby`/`aria-labelledby` on your control yourself, pointing at the same id.
