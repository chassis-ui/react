## Examples

Use one of the required contextual `color` props (e.g., `primary`) for styling. For inline dismissal, use the [dismissible prop](#dismissing).

<Example>
  <Notification color="primary">
    A simple primary notification—check it out!
  </Notification>
  <Notification color="secondary">
    A simple secondary notification—check it out!
  </Notification>
  <Notification color="success">
    A simple success notification—check it out!
  </Notification>
  <Notification color="danger">
    A simple danger notification—check it out!
  </Notification>
  <Notification color="warning">
    A simple warning notification—check it out!
  </Notification>
  <Notification color="info">
    A simple info notification—check it out!
  </Notification>
</Example>

<Callout context="info">
  <h5>Conveying meaning to assistive technologies</h5>

Ensure that information denoted by the context is either obvious from the content itself (e.g. the visible text), or is included through alternative means, such as additional text hidden with the <code>.visually-hidden</code> class.
  </p>
</Callout>

### Link context

Use `<Notification.Link>` to give matching colored links inside any notification.

<Example>
  <Notification color="primary">
    A simple primary notification with <Notification.Link href="#">an example link</Notification.Link>.
  </Notification>
  <Notification color="secondary">
    A simple secondary notification with <Notification.Link href="#">an example link</Notification.Link>.
  </Notification>
  <Notification color="success">
    A simple success notification with <Notification.Link href="#">an example link</Notification.Link>.
  </Notification>
  <Notification color="danger">
    A simple danger notification with <Notification.Link href="#">an example link</Notification.Link>.
  </Notification>
  <Notification color="warning">
    A simple warning notification with <Notification.Link href="#">an example link</Notification.Link>.
  </Notification>
  <Notification color="info">
    A simple info notification with <Notification.Link href="#">an example link</Notification.Link>.
  </Notification>
</Example>

### Additional content

Notifications can incorporate supplementary components like headings, paragraphs, and dividers.

<Example>
  <Notification color="success">
    <Notification.Heading tag="h4">Well done!</Notification.Heading>
    <p>Aww yeah, you successfully read this important notification message. This example text is going to run a bit longer so that you can see how spacing within a notification works with this kind of content.</p>
    <hr />
    <p className="mb-0">Whenever you need to, be sure to use margin utilities to keep things nice and tidy.</p>
  </Notification>
</Example>

### Dismissing

Add the `dismissible` prop to let users close the notification.

<Example>
  <Notification
    color="warning"
    dismissible
    onClose={() => {
      alert("Dismissed!");
    }}
  >
    <strong>Go right ahead</strong> and click that dismiss button over there on the right.
  </Notification>
</Example>
