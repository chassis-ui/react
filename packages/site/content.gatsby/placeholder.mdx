## About

Placeholders can be used to enhance the experience of your application. They're built only with HTML and CSS, meaning you don't need any JavaScript to create them. You will, however, need some custom JavaScript to toggle their visibility. Their appearance, context, and sizing can be easily customized with our utility classes.


## Example

## How it works

Create placeholders with the `<CxPlaceholder>` component and a grid column propx (e.g., `xs={6}`) to set the `width`. They can replace the text inside an element or be added as a modifier class to an existing component.

We apply additional styling to `CxButton`s via `::before` to ensure the `height` is respected. You may extend this pattern for other situations as needed, or add a `&nbsp;` within the element to reflect the height when actual text is rendered in its place.

<Example>
  <p aria-hidden="true">
    <CxPlaceholder xs={6} />
  </p>
  <CxPlaceholder component={CxButton} aria-hidden="true" disabled href="#" tabIndex={-1} xs={4}></CxPlaceholder>
</Example>

```jsx
<p aria-hidden="true">
  <CxPlaceholder xs={6} />
</p>
<CxPlaceholder component={CxButton} aria-hidden="true" disabled href="#" tabIndex={-1} xs={4}></CxPlaceholder>
```

<Callout className="mb-4" context="info">
  The use of <code>aria-hidden="true"</code> only indicates that the element should be hidden to screen readers. The <strong>loading</strong> behavior of the placeholder depends on how authors will actually use the placeholder styles, how they plan to update things, etc. Some JavaScript code may be needed to *swap* the state of the placeholder and inform AT users of the update.
</Callout>

### Width

You can change the `width` through grid column classes, width utilities, or inline styles.

<Example>
  <CxPlaceholder xs={6} />
  <CxPlaceholder className="w-75" />
  <CxPlaceholder style={{ width: '30%'}} />
</Example>

```jsx
<CxPlaceholder xs={6} />
<CxPlaceholder className="w-75" />
<CxPlaceholder style={{ width: '30%'}} />
```

### Color

By default, the `<CxPlaceholder>` uses `currentColor`. This can be overridden with a custom context or utility class.

<Example>
  <CxPlaceholder xs={12} />

  <CxPlaceholder context="primary" xs={12} />
  <CxPlaceholder context="secondary" xs={12} />
  <CxPlaceholder context="success" xs={12} />
  <CxPlaceholder context="danger" xs={12} />
  <CxPlaceholder context="warning" xs={12} />
  <CxPlaceholder context="info" xs={12} />
  <CxPlaceholder context="light" xs={12} />
  <CxPlaceholder context="dark" xs={12} />
</Example>

```jsx
<CxPlaceholder xs={12} />

<CxPlaceholder context="primary" xs={12} />
<CxPlaceholder context="secondary" xs={12} />
<CxPlaceholder context="success" xs={12} />
<CxPlaceholder context="danger" xs={12} />
<CxPlaceholder context="warning" xs={12} />

<CxPlaceholder context="light" xs={12} />
<CxPlaceholder context="dark" xs={12} />
```

### Sizing

The size of `<CxPlaceholder>`s are based on the typographic style of the parent element. Customize them with `size` prop: `lg`, `sm`, or `xs`.

<Example>
  <CxPlaceholder xs={12} size="large"/>
  <CxPlaceholder xs={12}/>
  <CxPlaceholder xs={12} size="small"/>
  <CxPlaceholder xs={12} size="xsmall"/>
</Example>

```jsx
<CxPlaceholder xs={12} size="large"/>
<CxPlaceholder xs={12}/>
<CxPlaceholder xs={12} size="small"/>
<CxPlaceholder xs={12} size="xsmall"/>
```

### Animation

Animate placeholders with `animation="glow"` or `animation="wave"` to better convey the perception of something being _actively_ loaded.

<Example>
  <CxPlaceholder component="p" animation="glow">
    <CxPlaceholder xs={12} />
  </CxPlaceholder>  
  <CxPlaceholder component="p" animation="wave">
    <CxPlaceholder xs={12} />
  </CxPlaceholder> 
</Example>

```jsx
<CxPlaceholder component="p" animation="glow">
  <CxPlaceholder xs={12} />
</CxPlaceholder>  

<CxPlaceholder component="p" animation="wave">
  <CxPlaceholder xs={12} />
</CxPlaceholder> 
```
