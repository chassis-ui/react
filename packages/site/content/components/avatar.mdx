## About

Avatars are typically used to display a user profile as a picture or short text. They can be used in various contexts, such as in lists, groups, or as buttons.

## Basic usage

Render a `<Avatar>` with text content for initials, or set the `src` prop to display a profile picture (aliased to `alt="Profile Picture"` by default).

<Example class="d-flex gap-small">
  <BasicExample client:load />
</Example>

Passing a `src` renders an `AvatarImage` automatically. Nest one directly instead if you need more control over the image itself.

<Example class="d-flex gap-small">
  <AvatarImageExample client:load />
</Example>

## Sizes

Set the `size` prop to one of the Chassis component sizes to adjust the avatar's dimensions.

<Example class="d-flex gap-small align-items-center">
  <SizeExample client:load />
</Example>

You can also use the `--cx-avatar-size` CSS variable to set a custom size.

<Example class="d-flex gap-small align-items-center">
  <SizeVariableExample client:load />
</Example>

## Custom components

`<Avatar>` renders a `<button>` by default. Set the `href` prop to render an anchor instead, or set `component` to render any other tag or custom component. Use the `disabled` prop to disable a button or anchor avatar.

  <CustomComponentsExample client:load />
</Example>

## Colors

Set the `color` prop to one of the Chassis themed colors to apply the appropriate background and text colors.

### Smooth style

Set the `smooth` prop to create avatars with a subdued background color and matching text color, for a softer, more subtle appearance.

<Example class="d-flex gap-small">
  <SmoothExample client:load />
</Example>

## Badges

Set the `status` prop to one of the Chassis themed colors to show a status indicator in the bottom-end corner. It scales with the avatar's `size` automatically.

<Example class="d-flex gap-small">
  <StatusExample client:load />
</Example>

<Callout context="info">
  <p>
    Status colors alone can be confusing for screen reader users. Set <code>statusLabel</code> to describe what the badge conveys &mdash; it's rendered as visually hidden text on the badge. Without it, the <code>status</code> value itself (e.g. <code>"success"</code>) is used as a fallback.
  </p>
</Callout>

## Stacks

Use `<AvatarStack>` to group related avatars together with a consistent overlap. Pass a `data` array to render a `Avatar` per item, or nest `<Avatar>` children directly &mdash; handy for a trailing "+N" overflow avatar. Set the `--cx-avatar-stack-spacing` CSS variable to adjust how much they overlap, and use the `size` prop to size every avatar in the stack at once.
