## Overview

`CxMenu` is a toggleable contextual overlay for links, buttons, and inline forms. It replaces the old `CxDropdown` family, is positioned using [React Aria](https://react-spectrum.adobe.com/react-aria/)'s `useOverlayPosition`, and handles keyboard navigation and multi-level submenus. Menus open on click by default.

## Examples

Compose `CxMenu` around a `CxMenuToggle` and a `CxMenuList`. `CxMenuToggle` renders the trigger button and `CxMenuList` renders the panel — Chassis positions it relative to the toggle automatically.

## Placement

Pass a `placement` prop to control which side of the toggle the menu opens on. It flips automatically when viewport space is limited.

<Example>
  <PlacementExample client:load />
</Example>

## Close behavior

The `autoClose` prop controls which clicks close the menu. The default (`true`) closes on any click inside or outside. Use `'inside'` or `'outside'` to restrict to one side, or `false` to require a programmatic `visible` change.

<Example>
  <AutoCloseExample client:load />
</Example>

## Submenus

Wrap a trigger and nested items in `CxSubmenu` to create a flyout. Submenus close sibling submenus automatically when a new one opens, and close along with their ancestor menu.

  <SubmenuExample client:load />
</Example>

### Submenus on mobile

Set `stacked` on a `CxSubmenu` to switch to a view-replacement pattern below the `small` breakpoint, and add `CxSubmenuBack` as the first item to let people navigate back to the parent level.
